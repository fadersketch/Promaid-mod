## 根因

v1.3.3 正式版把「巡逻航图」整章重写为「巡逻航路（轨道 · 目标点 · 减速点）」时，
只保留了说明与操作段落，**整块合成表段落被删掉**。配方 JSON 两树都正常，
`en_us.json` 里对应的英文译文键也一直留着（成了死键），所以游戏内只是**不显示**，
并非配方失效。

## 改动

两树 `GuideChaptersFlight.patrolGuide()`：在章节开头（道具介绍之后、画轨道步骤之前）
补回一段合成表——

- 正文：`§e合成§r（工作台，无序）：`；
- 配方块：`[[#shapeless;minecraft:paper;minecraft:compass;minecraft:ink_sac;>maid_smart:patrol_chart;@纸×1 + 指南针×1 + 墨囊×1（荧光墨囊也行）]]`。

显示用 `minecraft:ink_sac` 图标，说明里注明「荧光墨囊也行」；实际配方仍走
`maid_smart:ink_sacs` 物品标签（墨囊 / 荧光墨囊都认）。因为译文键与现有段落完全一致，
两树 `en_us.json` **不需要新增条目**。

## 边界

- 只改手册可见内容，配方 JSON、物品注册、标签与合成逻辑均未改动。
- 合成表按现有渲染器格式绘制：无序、三格材料 + 产物 + 一行说明。
- 英文客户端显示对应英文段落；配方 id 与说明中的物品名照旧。

## 验收

1. 打开游戏内「详细介绍」→「巡逻航路（轨道 · 目标点 · 减速点）」。
2. 章节开头能看到整块合成表：纸 ×1 + 指南针 ×1 + 墨囊 ×1 → 巡逻航图 ×1。
3. 用普通墨囊或荧光墨囊都能正常合成；其余章节与配方不受影响。
