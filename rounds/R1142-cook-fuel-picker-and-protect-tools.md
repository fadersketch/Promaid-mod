## 根因

两个独立问题叠在一起：

1. **面板候选网格只列方块**。烧制清单与矿表共用 `ensureCreativeCache()`，而它只收
   `BlockItem`——弓、弩、煤炭、生肉、骨头这类非方块物品**根本不在候选里**，
   玩家想禁掉"弓当柴烧"都找不到它。
2. **燃料选择把任何可燃烧、不可烧制的物品当"纯燃料"**。`extractBestFuel` 的第一轮是
   "纯燃料优先"（能烧且本身没有熔炼配方）；弓（原版燃烧 300 tick）正好落进这一档，
   而且燃烧时间比木板还长，于是排在最前面。`isSafeToFeed` 只拦"附魔/用旧过"，
   **全新干净的弓完全不拦**。

## 改动

### 1. 清单候选改为全部物品（两树 · 客户端）

新增独立的 `cookItemCache`（遍历物品注册表，不限方块）+ `ensureCookItemCache()`；
烧制/燃料两档的网格改用它。另加 `cookCandidates(fuelMode, level)`：按当前档位
（燃料 = 原版可燃烧；烧制 = 当前世界有炉子/烟熏/高炉配方）过滤一次并缓存 60 秒，
搜索框逐字输入时只做字符串匹配，不再每次重查整个注册表的配方。

### 2. 工具/武器默认不可当燃料（两树 · 服务端）

新增 `MaidCookBehavior.neverFuel(stack)`：**有耐久（最大耐久 > 0）、附魔、
TieredItem（木/石/铁/金/钻石/下界合金工具与剑）、ArmorItem、TridentItem、
ShieldItem、ProjectileWeaponItem（弓/弩/投掷武器）** → 永不当燃料。

- 挂在 `fuelListed` 上：`extractBestFuel` 与精妙背包 `pull` 两条取料路同时生效；
- 不受「只用这些燃料」放行——这是硬规则，与"附魔物品永不熔"同一档；
- `isSafeToFeed` 同时补上 `ProjectileWeaponItem`：原料侧也不会吞弓。

### 3. 面板表现（两树）

- 燃料档的弓/剑等显示为**红色 ✖（不可以）**；
- 点它 / 手填 id 会提示「工具 / 武器 / 有耐久的物品默认不能当燃料（硬规则）」，
  不写任何一张清单；
- 燃料档标题补一句「工具 / 武器 / 有耐久物品默认不可烧」。

### 4. 手册

「烧制与酿造」章：四张清单说明里补上"燃料档列出所有能当柴烧的物品（含弓、弩、
木制工具等非方块物品）"与"工具 / 武器 / 有耐久物品默认不可烧（红色 ✖，硬规则）"。
新增 48 条中英文手册译文（两树 `assets/promaid/i18n/en_us.json`）。

## 边界

- 工具/武器是**硬规则**，不提供"允许烧弓"的开关（避免误烧正在用的装备）；真要销毁请自己处理。
- 木棍、木板、原木等非武器可燃物仍可当燃料（第二轮"可烧制燃料兜底"逻辑不变）。
- 面板候选缓存 60 秒；整合包热加载新物品后重开面板或等 1 分钟即可见。
- 配方判定仍在客户端用当前世界配方表；客户端读不到世界时退回"全部物品"，不会把页面锁死。

## 验收

1. 打开「烹饪与酿造 → 烧制清单 → 燃料」页，搜索 `bow` / `弓`：能搜到，图标为红色 ✖；
   点击只出提示，不写清单。
2. 背包里只有一把干净的新弓、炉子缺燃料：她**不会**把弓塞进燃料槽；日志
   `cook round: ... nofuel`（没柴）而不是 `fedSlot1`。
3. 背包里有煤/木板：照常当燃料。
4. 燃料档搜索 `coal`、`beef` 等非方块物品：都能搜到（旧版这些也不在列表里）。
