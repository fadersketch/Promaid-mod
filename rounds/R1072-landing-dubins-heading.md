## 需求 / 来源

- 开发者反馈：「女仆基本上在平飞，高度基本上没怎么降。而且越飞越远。」

## 根因（日志实证）

- `进场航线 入口距=139 → 157 → 173 → … → 497`，`距接地点=24 → 41 → … → 356`：
  飞机没有沿航线进场，而是一路往外飞。
- 同一秒内反复 `定跑道`：`漂出钉住窗口 距接地点=361格 > 窗口=238格 → 重规划`。
- 三处叠加：

1. **入口切向写反**（主因）。跑道方向是 `(-sin(yaw), cos(yaw))`，而 Dubins 的角度约定是
   `atan2(dz, dx)`，入口切向必须是 `atan2(cos, -sin)`。旧代码写成
   `atan2(-sin, cos)`，入口航向差 90°～180°。航线终点虽然还是入口，但机头对着跑道外，
   捕获条件（航向差 <20°）永远不成立 → 一直重规划。
2. **钉住窗口太小**。`KEEP_D = 90 + 60 + 48 + 40 = 238`，而"从接地点附近掉头飞向
   160～200 格外的入口、半径上限 120"的路径最远可到接地点外约 440 格。掉头到一半就被
   判成"漂出"，每秒换一条跑道。
3. **进场航线 240 拍就过期**。这条路径 0.8 格/拍要飞七百多拍，12 秒一到就清空重规划，
   掉头永远飞不完。

## 改法（两树 `MaidMountCompat`）

- `planLandingApproach` 的 `endHeading` 改为 `atan2(cos(yaw), -sin(yaw))`，与
  `dubinsPoints`、`aircraftFollowApproach` 的角度约定一致。
- `AIRCRAFT_LAND_PLAN_KEEP_D` 238 → **560**（装得下掉头 + 入口 + 外扩）。
- 进场航线过期 240 → **1800 拍**（与 `aircraftFollowApproach` 的 stage 超时同口径）。
- 其余（入口 160～200 格 / 高 28 格、下滑角 0.12、捕获窗口 65～260、恒速进近、
  姿态限幅）均未改。
