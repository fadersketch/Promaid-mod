# R988 六项：轰炸触发改口径 / TNT 物理体积 / 树冠清理落地 / 接敌才接管 / 常用类去小类 / 第三方玩法模式黑名单扩项

## 排班

1. ① **轰炸与 TNT 触发改成「凡 IAttackTask 类战斗任务 + 有合法目标即触发」**（不再依赖任何命中边沿）。
2. ② **TNT 物理体积**（飞行中撞到敌人当场引爆，不再穿人）+ **追踪时长 0.5 秒 → 1 秒**（含老档迁移）。
3. ③ **伐木「树冠清理」选项落地**：查清它与名字不符 → 实施渐进版清冠 + 删死代码 + 校正三处文案。
4. ④ **接敌才接管**：战斗模式没有敌人时行为完整交还 TLM 原版（跟随模式跟主人、home 在家活动）；
   接敌立即接管、敌人清除立即复原；敌袭语音统一成同一口径；新增开关。
5. ⑤ **配置面板删掉「常用与一键预设」小类这一层**（面板 + 手册 + 译文表同步）。
6. ⑥ **第三方玩法模式黑名单扩项**：拔刀剑模式 + 战斗模式并入既有黑名单（`MaidModeCompat`）——
   只有「傀儡师」禁止自主切入；这两个模式可被自主参战 / 战中换战术 / LLM 自主切换切进去，
   切进去后本模组的战术与行动全体让位（保命动作除外）、敌人清除后照常还原（同日口径修正轮定型）。
7. 两树镜像 → 编译 → 14 护栏 FAIL 0 → 双 jar → 部署 4 实例 → 专服回归三件 → 文档台账 → 清临时。

## 需求 / 来源

- ①「不行，还是做不到。反正现在我要求就是那些具有 Iattack 类似标签的战斗任务都可以触发这个链路。」
- ②「扔出的 TNT 会直接穿过敌人导致扔偏（需要加上物理体积）」；「本身给予 TNT 的 0.5 秒追踪敌人
  时间是不够的，大概要 1 秒。」
- ③「我发现伐木设置里面那个树冠清理好像是一个废选项。」
- ④「女仆在没有敌人的战斗模式下还是不会像原版那样跟随主人……我想的是在没有敌人的时候女仆战斗
  状态的一切行为就跟她 tlm 原版的模式是完全一样的……只有接敌的时候（自己有攻击欲望）才立即走
  我们的链路，敌人清除以后立即复原。同时播报语音（附近的敌人清掉了，安全了……现在统一改成这个
  口径。）然后是我们做这个功能在配置项目里面要有可控开关。」
- ⑤「删除常用功能与一键预设这个小类。把所有内容直接摆在这里就行。不需要先跳转到这个小类。」
- ⑥「加入一个黑名单：女仆处于拔刀剑模式和战斗模式时，Promaid 所有的战术和行动逻辑都不介入。」
- ⑥ 口径修正（同日轮）：「不，我的意思是自主切换还是可以接过去的。默认切不过去的只有傀儡装配。
  其他那几项你也给我汇报一下。」

## 改法

### ① 触发口径（两树 `BombTntTick` + `MaidBombing`）

- `tickCombatTnt` 的 ② 段整段换掉：原来判「攻击冷却记忆由无到有」（枪械/三叉戟不写这个记忆），
  实测九百八十七 补过一条「目标身上最近打它的人是她」，仍要求伤害归在她名下（实测九百八十八 记的
  那一版）。现在只看 ① 解出来的**合法目标非空**（记忆优先、非法再按半径找，口径没动）——
  凡 `isCombatTask`（IAttackTask 接口优先 + UID 名单兜底）在手上有敌人就按既有节奏出手：
  先试轰炸起手（材料齐才动、相位自己收尾），未起手落到 ④ 投 TNT。
- 删掉随之失效的 `HIT_TRIGGER_TICKS` / `MaidBombing.LAST_HIT_TS` / `COOLDOWN_SEEN`（含 `forget` /
  `clearAll` 两处清理）。TNT 最短间隔、引信、材料与点火料判据一字未动。

### ② TNT 物理体积 + 追踪 1 秒（两树 `BombThrow` / `MaidBombing.Homing` / 配置）

- `Homing` 变成「在飞的那一发」的**监看记录**（不管追踪开关都登记）：加 `maid` / `track` /
  `expire` 与上一 tick 位置（`lx/ly/lz`）；有效期 = 引信 + 100 tick 兜底。
- `tickHoming` 每 tick 先取「上一 tick 位置 → 这一 tick 位置」这条扫掠线段，用纯算术点到线段距离
  （半径 = 敌人半宽 + 炸弹半径，候选先用线段外扩 0.75 格的盒子粗筛）判**命中敌人**——撞上就
  `setFuse(1)`：同一次 `ServerTickEvent.Pre` 里排后面的 PENDING 循环当 tick 在接触点引爆
  （模组自己的 TNT 形式不在 PENDING，走它自己那一炸，只是提前到接触瞬间）。只认敌人
  （`le == h.target` 或 `legalThrowTarget`），友军/主人/路人生物不触发。
- 追踪只在 `track && gameTime < until` 时转向（原限时 + 限转角不变）；目标没了只是停转向，
  体积监看继续。
- `combat.bombing.tntTrackTicks` 默认 10 → **20**（0.5 秒 → 1 秒）：配置注释、面板行文案同步；
  新增内部迁移标记 `tntTrack20Migrated` + `ProMaidMod` 迁移块（只搬还停在旧默认 10 的档）。

### ③ 树冠清理（两树 `MaidWoodBehavior` + 配置/面板文案）

- 查清：`wood.leavesClear` 一直在被读，但它只驱动 `burstNearbyLeaves`（**她自己身上** 3×3×3），
  而树叶长在树干周围/头顶——站在地上砍树的她碰不到，砍完树冠照旧浮着，观感就是「废选项」；
  配置注释与面板行还写着「树干连锁砍完后清上方树冠（BFS 半径 3）」，实为已删除功能的旧文案。
- 新增 `clearCanopy`（渐进版）：每砍掉一段木头（`isWoodState` 判过）就在这一段周围
  （水平 ±3、向上 6 格，单次上限 24 片）清掉树叶，音效/粒子与掉落物口径同 `burstNearbyLeaves`
  （自动收集进背包，否则落地，树苗永远进背包）；她搭的方块（`isWoodingPlaced`）不碰。
- 删掉空壳 `clearTreeTop`；配置注释与两树面板行改成实际行为（三段文案一致）。

### ④ 接敌才接管（两树 `CombatWorkRange` / `MaidWorkTags` / `PerceptionManager` / `SystemTTSManager` / 配置）

- 新增 `CombatWorkRange.attackDesireTarget` / `hasAttackDesire`：她**自己**有攻击欲望吗——
  脑里 `ATTACK_TARGET` 或实体层 `getTarget()`，活着且非友军（打雪仗写主人的那种不算）。
  不含「最近 5 秒挨打/打人」这类事后窗口与自保标记（那是 `inCombat` 扩圈用的口径）。
- 新增 `CombatWorkRange.chainDriverActive`：本模组的战斗驱动器真在开她吗（战术 / 自保 / 喂的目标 /
  扫帚 / 空袭 / 仿创造飞行）。全部是瞬时状态，敌人一清、驱动器一停当 tick 变 false。
- `MaidWorkTags.isChainDrive` 接战腿改成 `hasAttackDesire || chainDriverActive`；
  新开关 `combat.engageChain`（默认开，行「接敌才接管走位」挂「战斗与自保」）关掉 = 回旧宽判据
  （`inCombat`）。没有敌人、也没人驱动时走位完整交还 TLM（跟随跟主人、home 在家活动）。
- 敌袭语音（`PerceptionManager`）改口径：不再拿「她周围 12 格威胁数」快照差分判，改成
  **她自己接敌状态的边沿**——没目标 → 有目标 = 「有敌人靠近了！离我 X 格」（报她自己那个目标的
  距离）；有目标 → 没目标 = 「附近的敌人都清掉了，安全了」（至少跨过一次扫描才算，防一闪一没）。
  两条各用各的限频 key（`enemy_near` 吃 300 秒敌袭限频，`enemy_clear` 吃 30 秒普通事件限频）——
  旧版三个子事件共用一个 key，「靠近」播过后清敌语音 5 分钟内全被吞。
- `SystemTTSManager.bypassJarInterval` 加 `enemy_clear.ogg`（收尾台词不被内置包最小间隔吞）。
- 滞留探针（R986）判据同步新闸门口径：闸不咬即静默；咬住且「标记残留」或「无人驱动且无目标」
  才落一行——修复落地后探针在正常游玩下不再可能被误报。

### ⑤ 面板去小类（两树 `PromaidConfigScreen` / 手册 / 译文表）

- `Section.COMMON_PAGE` 标题「常用与一键预设」→「常用」（小类名不再出现在界面与手册里）。
- Neo 补上 `soleSectionOf` 的「返回」分支（forge 已有）：单小类大类的页内「← 返回分类」直接回首页。
- `openAt` 的「只给到大类名」分支：大类只有一个小类（如常用）时直接进那一页，不再落到「选择小类」层。
- 手册：功能总览的 ⓪ 常用链接文字改「常用」；面板导航章的结构句与返回按钮句补「只有一个子类的
  大类没有这一层」；`assets/promaid/i18n/en_us.json` 对应键值同步（护栏 `check_guide_i18n` 基线 0）。

### ⑥ 第三方玩法模式黑名单扩项（两树 `MaidModeCompat` / `MaidWorkTags` / `NeutralThreatDriver` / `CombatStallProbe` / 配置 / 面板 / 手册）

- 名单加两项（UID 制）：`true_power_of_maid:slashblade_attack`（真正的力量「拔刀剑模式」）与
  `ef_tlm:fight_mode_task`（史诗战斗联动「战斗模式」）——与原有「傀儡师」同一份表、同一套判据。
- 两级口径（口径修正轮定型）：`BLACKLIST` 三条 = **让位名单**（她处在其中任一条里，本模组战术与
  行动全体让位，`isPuppetMode` / `isSuspended`）；新增 `NO_AUTO` 集合 = **禁止自主切入**、
  只有「傀儡师」（`isBlacklisted` / `isBlacklistedUid`）——拔刀剑模式 / 战斗模式**允许**被自主参战、
  战中换战术与 LLM 自主切换切进去（它们照常进候选池），切进去之后同样全体让位。
- 闸口拆分：候选池排除（`AutoCombatPools` 池闸）与 LLM 工具闸（`SwitchTaskTool` /
  `PuppetModeLlmGuardMixin`）自动变「傀儡师 only」；`AutoCombatSwitch` 还原扫描跳过闸从
  `isPuppetMode` 换成 `isBlacklisted`——拔刀剑/战斗模式照常走还原链（敌人清除后送回战斗前任务）；
  新增 `retuneCombatTactics` 顶部名单闸（`isPuppetMode`）一处挡住两个调用点（593/608），保证在名单
  模式里战斗期间不换战术（换出 = 拆那个模组的玩法）；`AutoCombatTargeting` 的「已在模式里不重参战」
  闸保持（切进去之后这一战归那个模组打）。
- 本轮补齐三处此前没走让位判据的介入点：`MaidWorkTags.isChainDrive`（走位独占恒 false，否则接战腿
  会被她自己的攻击目标咬住）、`NeutralThreatDriver.drive`（不喂目标、不挥砍、不导航，只收回我们
  喂过的目标）、`CombatStallProbe.sweep`（让位中不判，防诊断噪音）。
- 文案与开关同步（两级口径）：「自主切换能切进去，「傀儡师」除外」——字段注释 / TOML 注释与
  comment / 面板行与 tooltip / 手册第⑪章四条 bullet + ⑧主动切换战斗句 + 战中动态换战术句；
  i18n 键值与英文逐对同步（`check_guide_i18n` 基线 0）；排班喂文与 `ScheduleManager` 日志照旧。

## 验收

- ① 枪械 / 三叉戟 / 法术 / 近战弓弩等**所有攻击任务**：只要她的任务手上有活着的敌人，就按最短
  间隔起手轰炸（材料齐时放水晶/重生锚/床）或投 TNT——不再出现「只有近战会扔」的偏科。
- ② 扔出去的 TNT 撞上敌人（或落地后敌人撞上来）会在**接触点当场引爆**，不再穿过敌人；离手后
  1 秒内朝目标小幅修正（每 tick ≤5°）。老档里 `tntTrackTicks` 还写着 10 的会被自动迁到 20，
  自己调过的值不动（迁移日志搜「TNT 追踪时长迁移」）。
- ③ 开着树冠清理时，砍树过程中头顶/四周的树叶会**跟着砍树逐层被清掉**（砍一段清一段，
  音效粒子同玩家挖方块，掉落进背包）；关掉开关 = 只砍树干、树叶自然衰减。
- ④ 战斗模式 + 周围没有敌人：跟随模式她照旧跟着主人、守家模式在家按原版节奏活动
  （原版 TLM 行为一字不差）；一旦接敌，战斗链路立即接管走位；敌人清除后立即交还。
  开关「接敌才接管走位」关掉 = 回旧口径（含最近 5 秒挨打/打人）。
  接敌/清敌语音按同一口径播报，且「清掉了」不再被「有敌人靠近」的限频吞。
- ⑤ 配置面板点「常用」直接进参数页，页内返回直接回首页；界面与手册里不再出现
  「常用与一键预设」这个名字；手册 ⓪ 常用链接仍可一键跳转。
- ⑥ 装《真正的力量》/《史诗战斗联动》的整合包里：自主参战 / 战中换战术 / LLM 自主切换**能**把
  「拔刀剑模式 / 战斗模式」当普通战斗任务切进去；切进去之后（不管谁切的）本模组的战术与行动全体
  让位（走位归那个模组、不投弹不轰炸不威胁驱动不自动换装不排班换段），保命动作照常，她按那个
  模组的打法打完；敌人清除后自动化链路照常把她还原回战斗前的任务。**「傀儡师」例外**——自主
  切换永不切入（它不在战斗候选的语义里），想进它只有手动切。

## 边界

- ① 的触发判据仍要求目标是**她的任务认的敌人**（`legalThrowTarget`：IAttackTask.canAttack +
  非友军）；「按半径找」的老兜底保留，只是记忆里没合法目标时才走。
- ② 体积判定只认敌人：主人/同主女仆/友军/普通生物都不触发引爆（不然路过一头牛就把炸弹带炸了）。
  方块仍可穿过（原版 TNT 无方块碰撞），本条只解决「穿敌人」。
- ② 起爆这一炸仍是既有的一炸（默认不破坏方块、不伤友军、粉色标记），只是**时机**提前到接触点。
- ③ 只清树叶（原木是正常挖掘目标），只清「砍掉那一段周围 ±3/向上 6」且单次上限 24 片
  ——刻意不做「整棵树冠一次消失」（那正是早年删掉 BFS 清冠的反馈）。
- ④ 开关只影响**战斗链路走位独占**：挖矿/伐木的独占、飞行/扫帚/自由飞的驱动腿原样保留。
  home 模式照旧不独占（实测九百一十四）。语音只改判定口径与限频 key，文案一字未动。
- ⑤ `Section.COMMON_PAGE` 作为行容器与深链目标保留（手册链接按枚举名匹配，不受标题改动影响）。
- ⑥ 名单是 UID 制：没装对应模组时那一条等于不存在（`ef_tlm:fight_mode_task` 目前没有实例装它，
  属预防性登记）；名单只影响「自主切换口径」与「让位」，**从不拦玩家手动切换**——拔刀剑/战斗
  模式可被自主切换切进去，切进去后本模组不再动她直到敌人清除（此时还原链照常把她送回原任务）。
- ⑥ 让位只针对战术与行动：自保、落地水、防火、宠物免疫四类保命动作仍在（口径同傀儡师）；
  该模式下滞留探针不判，避免诊断噪音。
