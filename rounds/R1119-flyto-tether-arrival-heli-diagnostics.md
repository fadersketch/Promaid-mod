## 评估（日志实证）

### ① 绳子为什么"一起飞就断"

```
03:33:03 [飞行跟随] 飞向指定坐标（167.8 格），背上鞘翅追过去
03:33:03 [武装拴绳] 起飞挂载：…（从牵绳翻成二号位）
03:33:03 [武装拴绳] 解除(玩家离鞍)：女仆=…
```

- 挂载本身成功（没有「起飞挂载失败」）。下一拍 `maid.hasPassenger(player)` 却是 false。
- 根因：她一起飞就成了"离主人 47/100 格以上"的远行目标，TLM 的 `teleportToOwner`
  在下一拍触发；它走 `Entity.teleportTo`，而 `teleportTo` 会 `unRide()` ↔ `ejectPassengers()`
  —— 把刚挂上的玩家从她背上卸下来。我们第二拍看到"不在乘客表里"，就按"玩家离鞍"把链路解除了。
- 同一趟里还有第二条手：`[空袭牵引绳] 距主人 101 格（> 100 格），已传送回主人身边` 反复刷屏
  （03:33:06–03:34:05，十余次）。它每次也都走 teleport，把这一趟按回主人身边。

### ② 直升机：日志说在沿轨，观感却在爬升

```
03:31:17 [航迹飞行] home=true 本拍航迹点=true
03:31:17 [模组坐骑] 飞行档 … 跟随档(比主人高3格) 距目标=0格 高差=3 竖直速度=0.19
03:31:42 [模组坐骑] … 高差=-62
03:31:47 [模组坐骑] … 高差=-177
```

- 03:31:17–03:31:37 高差恒为 3、竖直速度 +0.19：目标始终在她上方 3 格 = **目标跟着她涨**，
  这是"以主人 Y 为基准"的跟随档特征，不是固定航迹点。
- 03:31:32 起 `home=false`。此时 `effective` 已按 R1118 对飞行载具放行，`patrolFlight/patrol`
  也确实是 true，但日志只证明"算了航迹点"，没证明"最终喂给控制器的是哪个点"。
- 因此本轮的处置是：**只要她身上绑了航迹（哪怕还没闭环/点数不足），就绝不进入跟随主人的分支**；
  并把每一拍的 branch / 判定说明 / 最终目标点写进日志。这样下一轮要么直接看到"分支=航迹 目标=(x,y,z)"
  且高度稳定，要么能读到 `说明=航迹未闭环` 之类的确切原因。

### ③ 断绳之外还有哪些"阻挠"

- 同维度远距拉回（48 格）在她起飞的窗口期还没标记"飞行跟随中"，会先把她传走。
- 自保归位传送（`teleportHome` / `teleportHomeOnExit`）也会打断这一趟。
- 扫帚牵引绳（100 格）对扫帚「飞过去」同样会拽回。
- 飞行跟随的 canUse/canContinue 里还留着睡/骑/坐、home、自保三道闸。

## 改动

### ① 断绳（两树）

- `MaidTeleportPreserveMixin`：`isTethered` / `MaidTravelTarget.active` /
  `MaidFlightFollowBehavior.isFollowing` 任一成立 → TLM 的 `teleportToOwner` 直接返回 false。
- `MaidChunkLoadManager.trySameDimPull`：`active(travel)` 或 `isHanging` → 不拉回。
- `MaidFlightRecall`：`active(travel)` 或 `isHanging` 或 `isFollowing` → 牵引绳整条静默。
- `MaidBroomRecall`：`active(travel)` → 静默。
- `SelfPreservationBehavior.teleportHome/teleportHomeOnExit`：`active(travel)` → 不归位。
- `GunnerTetherManager`：新增 `HANG_GRACE`（挂上后 2 秒）。乘客关系被外部抖掉时，
  若玩家当前不在别的载具上 → 当场 `startRiding` 重挂并记 `[武装拴绳] 重新挂载`；
  只有重挂失败才走原来的"解除(玩家离鞍)"，日志追加 `玩家坐骑=…`。
  另外「飞过去」期间她换任务不再自动断链（直接接受新 kind）。

### ② 到点（两树 `MaidTravelTarget`）

- 判据改成 **5×5×5 包围盒**：`|dx|,|dy|,|dz| ≤ 2.5` 即到点，不再用球形距离 / 地面 1 格。
- 到点：清目标 + 日志 `[飞过去] 已到达目标点附近（5×5×5）…` + 给主人
  `§a✦ … 已到达目标点附近，本次飞行结束`。

### ③ 飞过去期间静默（两树 `MaidFlightFollowBehavior`）

- canUse 与 canContinue 的睡/骑/坐、home、自保三道闸都加 `!travel`。
- 原有的总开关、威胁、接敌、任务占用、超时在 R1118 已对 travel 让路；至此只剩
  "目标是否存在"与"她物理上有没有鞘翅/推进剂"两条硬条件。

### ④ 直升机（两树 `RideBindManager` + `PatrolFlight` + `MaidMountCompat`）

- 新增 `routeBound`：`bindMaid` 过（哪怕未闭环）就绝不进入"跟随主人"分支。
  - 有航迹点 → `分支=航迹`
  - 有效但本拍无点 → `分支=航迹·本拍无点→悬停`
  - 绑了但未生效 → `分支=航迹未生效→悬停`
  - 未绑定 → 机上有人 = 悬停；否则才跟随主人。
- `[航迹飞行]` 每 5 秒一行：`home=… 绑定=… 生效=… 说明=… 分支=… 目标=(x,y,z)`。
  `说明` 由 `PatrolFlight.explain` 给出（总开关 / 任务 / home / 未绑定 / 点数不足 / 未闭环 / 跨维度）。
- `[模组坐骑]` 那一行追加 `避险抬升=…`：若无限向上是 `vehicleAvoidLift` 把目标点每拍抬高，
  下一轮日志会直接显示这个数。

## 边界

- 物理上飞不了（没有鞘翅/推进剂）仍然不飞——这是"她做不到"，不是阻挠；日志会写
  `飞行跟随跳过 … 背包里没有可用鞘翅/可以飞行的道具`。
- 到点后目标即清除；想再飞一次要重新点「飞过去」。
- 头盔/饰品位的 home、坐垫等停放语义不变：非「飞过去」时该停照样停。
- 直升机"绑了航迹但未闭环"时是**悬停等补完**，不是起飞巡逻——不会再追主人，也不会无限爬升。
- 版本号仍为 **1.3.3**，同号重打；发布素材等验收后再写。

## 验收

1. **飞过去不断绳**：拴绳绑住跟随女仆 → 航图「飞过去」→ 她起飞后玩家应被挂到二号位并
   一直吊着；日志出现 `起飞挂载`，**不再出现**同一秒的 `解除(玩家离鞍)`；
   全程不再刷 `[空袭牵引绳] 距主人 … 已传送回主人身边`。
2. **5×5×5 到点**：她飞进目标点 ±2.5 格后，日志出现
   `[飞过去] 已到达目标点附近（5×5×5）`，聊天栏出现「本次飞行结束」，目标清除。
3. **阻挠静默**：飞行途中附近有怪、任务占用、低血自保、她换任务，都不应中断这一趟。
4. **直升机沿轨**：绑一条闭环航迹后搜 `[航迹飞行]`，应看到 `生效=true 说明=生效 分支=航迹`
   与固定的 `目标=(x,y,z)`；`[模组坐骑]` 的高度应稳定在目标附近，不再出现
   `高差=3` 每拍不变 + 竖直速度持续为正的爬升棘轮。
5. **未闭环航迹**：应看到 `说明=航迹未闭环 分支=航迹未生效→悬停`，机身原地悬停而非追主人。
