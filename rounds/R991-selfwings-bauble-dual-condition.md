# R991 自推鞘翅（壮丽鞘翅这类）装在饰品栏时「两个条件只认一个」——判定放宽到「能穿上」

## 排班

1. ⑪ **自推鞘翅的资格判定放宽**：`MaidSelfPropelledWings.hasWings` 从「只看胸甲槽」放宽到
   「**能不能把它穿到胸甲槽**」——胸甲槽 / 双手 / 饰品栏（Curios）/ 背包（含精妙背包、
   旅行者背包）里的那一件都算；胸甲槽被**别的**鞘翅占着则不算（装备取舍不替玩家换鞘翅，
   判定不许比取用宽松）。判定与取用收在同一处（新 `MaidFlightKit.canWearSelfWings`）。
2. ⑪ **取用侧同源**：`equip` / `takeElytra` 的第一优先级改为「自推鞘翅」（新 `takeSelfWings`：
   背包 → 双手 → 饰品栏）——她身上有那件就穿它，不会出现"判定认了、穿上的却是另一件"。
3. ⑪ **缺件诊断补一项**：`MaidSelfPropelledWings.diag` 增加 `可获得=`（现在能不能靠它飞）。
4. 两树镜像 → 编译 → 14 护栏 → 双 jar → 部署 4 实例 → 专服回归三件 → 文档台账 → 清临时。

## 需求 / 来源

- ⑪「像壮丽鞘翅这种特殊的鞘翅，我们在代码里面是把它判断，又满足了烟花的条件又满足了鞘翅的
  条件。这一点在把它装在装备舱里的时候确实生效，但是把它装在饰品栏的时候又只认其中一个了。」
- 代码实证（两树同构，逐条读过）：
  - **鞘翅条件**（`MaidFlightKit.hasElytra` → `isElytraLike`）扫 **胸甲槽 / 双手（含被借走的
    副手）/ 饰品栏（Curios，实测六百八十 起）/ 背包（含额外容器）** —— 壮丽鞘翅在饰品栏里被认 ✓；
  - **烟花条件**（`hasFlightPropellant` 的自推鞘翅那一支 → `MaidSelfPropelledWings.hasWings`
    → `wornWings`）**只读胸甲槽** —— 同一件在饰品栏里不被认 ✗。
  - 于是 空袭 `isModeActive` 为假 → 走 `notifyNotReady`（气泡报「没有可以飞行的道具」）→
    `equip` 那一步根本走不到；而 `equip` 的「第三来源：饰品栏」（实测六百八十）本来就会把
    它取来穿到胸甲槽——**坏的只是判定**（取用侧早就通了）。

## 改法

### 判定（`MaidFlightKit.canWearSelfWings` + `MaidSelfPropelledWings.hasWings`）

- 新 `canWearSelfWings`（public）：①胸甲槽那件在自推表里 → true（与旧版一字不差）；
  ②胸甲槽是**别的**鞘翅 → false（`equip`/`takeElytra` 都不会替玩家换掉一件能滑的鞘翅，
  判定与取用同口径）；③否则 双手 → 饰品栏（Curios）→ 背包（含额外容器）里有没有
  「在自推表里 + 自己会滑翔（`isElytraLike`）」的那一件。
- 新谓词 `isWearableSelfWings`：开关开着 + 在自推表里 + `isElytraLike`——穿上之后原版滑翔
  闸门认的正是它，缺这一条就会"判定说能飞、她却在往下沉"。
- `hasWings` = `enabled() && MaidFlightKit.canWearSelfWings(maid)`；`wornWings` **不动**
  （推力仍只从胸甲槽那件发——原版 `updateFallFlying` 只认胸甲槽的硬约束）。

### 取用（第一优先级：自推鞘翅）

- 新 `takeSelfWings`：背包 → 双手 → 饰品栏，只取自推鞘翅；`equip` 与 `takeElytra` 原有
  各趟扫描**前面**各加这一趟——她有多件鞘翅时起飞优先穿那件"不需要烟花"的，普通鞘翅留包里。

### 诊断

- `MaidSelfPropelledWings.diag` 增加 `可获得=`（`canWearSelfWings` 的布尔）——现场日志里
  「胸甲=空 / 可获得=false」一眼看出卡在哪一半。

## 验收

- 壮丽鞘翅（及伊卡洛斯空域系等自推鞘翅）**放进饰品栏**：照样被认作「有鞘翅 + 有不必烧烟花的
  推进剂」——空袭能激活、飞行跟随能起飞；起飞前她会先把它取来穿到胸甲槽（与"放背包"同一路）。
- **装在胸甲槽**：行为与旧版一字不差（`wornWings` / 推力口径未动）。
- 她身上有多件鞘翅（普通 + 自推）时：起飞穿**自推那件**（不烧烟花），普通鞘翅留在背包。
- 胸甲槽已被别的鞘翅占着、自推那件在饰品栏/背包：与旧版一致地报「没有可以飞行的道具」——
  不替玩家换掉正在穿的那件鞘翅（日志 `自推鞘翅: … 可获得=false` 可复核）。

## 边界

- 只认**自推表里的件**（`combat.selfWingsItems`，默认伊卡洛斯空域系 6 件 + 神秘遗物+ 两件）；
  `combat.selfWings` 关掉 → 判定与取用一起退回旧口径（"只当会滑翔的胸甲"）。
- 推力每一条仍只从**胸甲槽**发（`wornWings` 不动）：饰品栏/背包里的那件必须先穿上，才谈得上推。
- 「饰品栏」= Curios（TLM 自带饰品栏的 `isItemValid` 不收鞘翅，字节码实证 → 实测六百八十 起走
  `CuriosElytraCompat` 全反射软兼容）；Curios 不在场 / 反射失败 → 一切按"没有饰品栏鞘翅"，
  与旧版一字不差。
- 手部 / 背包里的那件也算「可获得」：与鞘翅条件（`hasElytra` 本来就扫这三处）同范围；
  没有这几件的存档逐项与旧版一致。
- ⑪ 修的是**已交付行为**（实测六百八十 的饰品栏鞘翅与 实测七百一十 的自推鞘翅都在 v1.3.0
  之前的发布里交付），写入玩家文案（「修复」一条）。
