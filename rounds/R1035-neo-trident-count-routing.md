## 需求 / 来源

- 开发者原话：
  「主手武器为激流三叉戟时能否也安排类似的分人数战术？人数<=3不变，人数>3变为长矛同款
  移动逻辑，只是在接近时改为释放一次三叉戟攻击，其他不变。」

## 评估

- 三叉戟原本在空袭里只有一处攻击：通用链路收翅俯冲时 `smashHit` 调
  `MaidTridentSpinBehavior.tryStartDash(airborne=true)`。单目标下这套几何已经够用，**保持不变**。
- 群怪时把同一套进场（35° 爬升、固定斜率俯冲、贴地保护、命中后水平保持、再点火）交给
  `SpearAirRaidBehavior`，只在进入 `MaidTridentSpinBehavior.dashRange()`（4 格）时把手里的
  "水平点火贯穿"换成一次旋转突刺：
  - 不点烟花、不写长矛蓄力（`SpearCoreCompat` 全程不参与）；
  - 起手前收翅，突进期间本链路**完全不碰**滑翔位、速度与旋转动作，避免滑翔的 `travel`
    把突进速度拽回去；
  - 突进结束（`isDashing` 变假）后回 `RECOVER`，等水平矢量耗尽再走通用起飞链；
  - 伤害完全由旋转突进自己的 `onSpinTouch` 结算（攻击力 + 附魔），本链路不加路径扫掠补判；
  - 日志主题改为「空袭·三叉戟」，接管/退出/命中日志都带武器名。
- 群怪阈值、16 格计数半径、0.5 秒退出确认与长矛完全共用；`>3` 才接管，`≤3` 交回通用空袭。

## 边界

- 仅 1.21.1 NeoForge；1.20.1 的镜像**等开发者验收批准后再做**。
- 三叉戟分流由它自己的总开关 `combat.riptideDash` 控制；长矛分流仍由
  `combat.spearAirRaid` 控制，两者互不影响。
- 三叉戟的群怪进场只复用**移动几何**；出手仍是原来那一记旋转突刺，伤害/冷却/收招不变。
- `≤3` 的三叉戟行为与改动前逐字节一致（通用空袭的 `smashHit` 入口）。
- 版本号仍为 1.3.3（同号重打）。

## 验收

1. **单目标 / boss（三叉戟）**：附近 ≤3 个敌人时与现在一致——通用空袭爬升/俯冲，临门一次旋转突刺。
2. **群怪（三叉戟）**：附近 >3 个敌人时进入长矛同款进场（日志「接管控空（三叉戟，群怪 N 个…）」），
   接近后日志出现「激流旋转突刺（距敌 X 格）」，旋转期间不应被滑翔减速或拽回。
3. **收尾**：突刺结束后应回到水平保持、矢量耗尽后再次点火，不落地、不重复起手。
4. **组队边界**：群怪打散到 ≤3 后约半秒退出独立链路（日志「退出三叉戟空袭独立链路」），改按单目标规则打。
5. **长矛回归**：持长矛时行为与 R1034 一致（>3 独立链路、≤3 通用链路 + 0.5 秒冲锋）。
