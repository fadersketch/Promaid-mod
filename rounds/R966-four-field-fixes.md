## 评估
1. **导入蓝图（回退 + 排版）**：R965 的"系统文件框优先"在开发者环境**弹不出来**（AWT 不可用）→ 按"继续沿用原来的MC内置GUI"把 `openPreferred`/AWT 路径**整段删除**，两个导入按钮回到 `FilePickScreen.open`。内置浏览器本身的错位根因：**每页行数写死 12 行**、条目区与底部翻页行（`h-28`）互不知道对方存在——GUI 缩放调大时（实测截图约 4×，有效高 ≈245）12 行一直画到屏外并压住翻页行；按钮写死 300 宽，窄窗口上顶出两侧。级别 P2（界面可用性）。
2. **飞行跟随（防烧料）**：静态排查后**"稍远即丢目标"的判据找不到**（`aimOf` 实体档在主人同维度时不会返回 null）；可证的两条烧料路径是：①"追不上"没有任何停损——只靠 60 秒 `MAX_TICKS` 超时，期间每 1.5 秒补推一发；②收手即刻可再起手，"落地→起飞"抖动会一枚一枚烧。本轮补两道闸止损并把"没进展"写进日志（供定位真正根因）。级别 P1（浪费玩家物资）。
3. **瞬移回退**：1 tick 与 2 tick 的差别只是"放行更多"，**×1 档完全不瞬移在代码里找不到机制解释**（如实留痕；若回退后 ×1 档仍不传送，需要现场 `promaid.log` 与复现细节再查）。本轮按指令回退 2 tick。级别 P2。
4. **搜索框**：javap 实证（1.20.1 SRG）：`EditBox` 构造参数里的 Component 只用于**朗读**；可见提示来自 `f_256828_` 字段（由 `m_257771_(Component)` = setHint 写入）；无边框（`m_94182_(false)`）时框体与底色都不画——于是"值为空 + 未聚焦 + 无 hint"的 EditBox **一个像素都不画**。此前把它改成无边框后正好落在这三个条件的交集上。级别 P1（面板主要入口观感）。

## 改法
1. **两树 `gui/FilePickScreen`**：删除 `openPreferred`（R965 整段）；布局改为**按屏幕现算**——`rowsPerPage() = max(1, (高-34-80) / (ROW_H+2))`（列表区 = 顶部 80 到翻页行之上，行距 `ROW_H+2`），`m_7856_`/`render` 两处统一用它；按钮宽收窄为 `bw = min(300, 屏宽-16)`、横位 `bx = cx - bw/2`，全部按钮 bounds 走 `(bx, y, bw, …)`。
2. **两树 `build/BlueprintBookScreen`**：两个导入入口回到 `FilePickScreen.open(...)`（注释改写为"系统框弹不出来→回内置浏览器"）；搜索框补一条 `setHint("搜索建筑名称…")`（forge `m_257771_(Component.m_237113_(…))` / neo `setHint(Component.literal(…))`）。
3. **两树 `build/MaidBuildBehavior`**：`TELEPORT_MIN_INTERVAL` 1 → **2 tick**（注释链改为 4 → 实测五百五十六 2 → 实测九百六十四 1 → **实测九百六十六 回退 2**）。
4. **两树 `combat/MaidFlightFollowBehavior`**：新增 `RESTART_COOLDOWN=60` / `PROGRESS_TIMEOUT=100` / `PROGRESS_EPS=1.5` 与四张表（`LAST_STOP` / `BEST_DIST` / `LAST_PROGRESS` / `STOP_NOW` / `CHASE_BLOCKED`）。tick 里每拍记账：比本趟历史最近距离再拉近 `PROGRESS_EPS` 才更新"最近拉近时刻"，5 秒没拉近 → 判「追不上」：`STOP_NOW` 收手 + `CHASE_BLOCKED` 暂禁自动起手（**坐标档是一次性任务，只收手不封禁**）；canUse 两条新闸（起手冷却 / 追不上封禁）排在贵判定之前，且"距离不够"那一支里**解除封禁**（回到起手距离内）；stop 里记 `LAST_STOP`、清本趟痕迹、`CHASE_BLOCKED` **不在此清**；「结束」日志追加「5 秒没拉近——判「追不上」，收手不再烧推进；」；`forget`/`clearAll` 全量清理新表。
