## 改法

### 字段重叠（`BlueprintBookScreen`）

根因两处：① 回执行画在 `PANEL_TITLE_Y + 18`（y=54），而状态区首行从 `CONTENT_TOP + 4`（y=56）起画——
字体高 9px，两行必然相撞；② 渲染用 `CONTENT_TOP + 4` 作状态起点、按钮侧却按 `CONTENT_TOP + 12 + 行数×11 + 10`
算列表起点，两个口径不一致，列表按钮也会压住状态末行。

改法：抽出**分区原点**（状态区 `CONTENT_TOP + 8`、列表 `状态起点 + 行数×行高 + 8`），渲染与按钮共用同一套算式；
回执行独占第三行；页码画在翻页行（`h - 20`），不再与状态行抢位。

### 一页多塞 + 跳转（`BlueprintBookScreen`）

- 状态区**默认收起**（`debugStatusOpen`，左下角「状态 ▾」开关）。旧版状态区常驻 6~10 行 + 选中项全文两行，
  列表只剩两行；收起后整页都是列表。
- `DEBUG_ROW_H` 20 → **16**（行距 17）。
- 动作按钮从两行挪到底部固定位置（`h-64` / `h-44`），翻页行固定在 `h-24`。
- 翻页补 **⏮ / ⏭**（首页 / 末页），与 ◀ ▶ 一起构成跳转；页码居中显示。
- 展开状态时，开关按钮上直接写「状态 2/3 ▴」，省掉一行页码。

### 「停用关系」说清楚（`BlueprintBookScreen`）

- 按钮改名：「停用关系」/「**启用关系**」（原来叫「恢复关系」，与「恢复」记忆撞词）。
- 标题下第二行改为**按选中项**写明语义（`debugContextHint()`）：
  - 没选中 → 通用提示 + 当前条数 + 翻页键说明；
  - 选中记忆 → 「↑↓改重要度、强化削弱调权重；作废后不再被想起（可恢复）」；
  - 选中有效关系 → 「停用只是让她不再想起它，记录保留、随时可启用」；
  - 选中已停用关系 → 「点「启用关系」她就重新想起它」。
- 第三行改为**上一步回执优先，否则显示选中那条的全文（单行）**，再否则显示刷新时刻。

### 记忆与日记去重（`BlueprintBookNetworking`）

记忆页里的「记忆日记（共 N 篇，最新：）」+ 6 行摘要整块删除，换成一行入口：
「女仆日记：共 N 篇——点上方「日记」页签翻看（目录 + 逐日正文）」。两树同改。

### 两个新气泡进语音包

- `assets/promaid/voice/manifest.json`（两树同文件）新增两条 `contains` 词条：
  「这片区域没有目标矿物了」→ `mine_area_cleared.ogg`；
  「这片区域没有可砍的树木了」→ `wood_area_cleared.ogg`。
- `tools/voice/gen_voice_pack.py`：补两条日语台词并挂到 `work` 声线档
  （「この辺りにはもう目当ての鉱石がないみたい、しばらくここらで動いてるね～」/ 树木同款）。
- 合成链路：本地 GPT-SoVITS（`D:\GPT-SoVITS-v2pro-20250604-nvidia50\API.bat`，127.0.0.1:9880）
  → `gen_voice_pack.py run mine_area_cleared.ogg wood_area_cleared.ogg` → `norm_voice_pack.py`
  （峰值归一化 -1.5 dB + ogg q4）→ `install_voice_pack.py`（按 manifest 装进两树 assets）。
- 合成完把 TTS 服务停掉（它本来就没在跑，用完还原），临时目录 `_voice_new2` 删除。

## 边界

- 状态区默认收起是**默认值**，没有持久化（每次进页面都从收起开始）。
- 行高 20 → 16 会略微压缩原版按钮贴图（换来一页 3 倍的条目数）。
- 新语音只影响**新装包**：jar 内的 assets 已更新，但玩家本地若装过旧语音包，需重新导入语音包才听到这两句。
- TTS 服务未随包分发：本次只是用它合成，用完已停（下次要补台词仍按同一套 `API.bat` + 三个脚本）。
