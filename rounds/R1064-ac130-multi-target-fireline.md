## 需求 / 来源

- 开发者反馈：「在对付少量敌人的时候打得很准，但对付多个敌人的时候，就很容易出现炮弹先
  打到地上而追踪不了的问题。所以说，首先炮管需要先拉一条线到自己准备攻击的敌人，那么子弹
  的初始开始方向就应该先沿着这条线。」
- 同轮确认：5 个 TNT ≈ 250 点伤害已经正常，**本轮不碰 TNT**。

## 评估

追踪链路本身没坏；问题出在「开火那一刻炮弹朝哪」与「这一发该追谁」两处，且只在多目标时暴露：

| 机制 | 旧行为 | 多目标时的表现 |
|---|---|---|
| 直瞄开火闸 | `directFireAt` 直接按解算方向生成炮弹，**不等炮管转到位** | 炮塔/机头还指着上一个敌人，炮弹先沿旧朝向飞出，再靠 25°/拍纠向；近距离先撞地 |
| AC-130H 侧射炮 | 固定炮写死在左舷，没有「目标必须在这一侧」的检查 | 目标绕到右舷时也开火，炮弹从机身/机翼里穿出，首发就撞地形 |
| `MaidShellHoming.PENDING` | 一只女仆**一个槽**，后一门炮的目标覆盖前一门 | 同一 tick 两门炮打两个敌人，先出的那发被认成后一个目标，拐向另一边扎地 |

实机日志（21:00～21:05）里的顺序与此吻合：先是「认领」距离正常，随后同一只女仆连续多拍
`纠向` 的目标在两三个敌人之间来回跳，落点日志出现大量「目标坐标与最后位置高差为正」的贴地结束。

## 改法

### 1. 开火前先把炮管拉到目标连线上（两树 `MaidMountCompat.tickAttack`）

- **可转炮架、非炮艇**：每一门炮单独算 `firingSolution`，`aimErrorDeg` 超过
  `AIM_ALIGN_DEG`（3°）就按住这一门，只打别的已经对正的炮；日志
  `模组坐骑·按住` 写「炮管与目标连线夹角 N°（等炮塔转到位）」。
- **固定炮、非炮艇**（AH-6 机炮这类）：等机头对准（`aimed`），或连续
  `AIM_FORCE_TICKS`（2 秒）对不上后的兜底硬打；否则按住。
- **侧射炮艇（AC-130H）**：不额外等炮塔，交给下面 `directFireAt` 的两道固定炮闸。

### 2. 固定炮的「炮管侧 + 炮口净空」闸（两树 `MaidMountCompat.directFireAt`）

- **炮管侧**：`shootVecOfGun` 与解算方向的点积 ≤ 0（目标在炮管背侧）→ 不发射。
- **炮口净空**：从炮口沿解算方向 `clip` 16 格，命中任意碰撞方块 → 不发射。
- 两道闸都只按住**这一拍**，下一拍按新的盘旋位置重算；正常侧射窗口打开就恢复。

炮弹的初始方向仍是 `firingSolution`（引擎自己的 `calculateFiringSolution`：重力下坠 +
提前量），炮口取 `getShootPos(炮名)`——即「炮口 → 目标」这条线本身。本轮做的是**不再在
炮管还歪着的时候扣扳机**，让首发方向从一开始就贴着这条线。

### 3. 待认领记录改成按炮口逐发排队（两树 `MaidShellHoming`）

- `Pending` 增加 `muzzle`（炮口坐标）与 `expireAt`（2～3 拍过期）。
- `noteSpawned(maid, mount, target, muzzle)`：直瞄开火**当场**登记，`directFireAt` 里调用。
- `note(...)`：只服务引擎原路（投弹/直瞄反射不可用，弹体延迟生成），炮口记 `null`。
- `claim` 改为：同一只女仆的记录是一个列表，按**炮弹位置离炮口最近**匹配（12 格内），
  取走即删；没有炮口记录的才退回最早那条无炮口的。
- `tickAttack` 只在 `engineShot == true` 时补 `note(...)`，直瞄那一档不会一炮记两条。

## 验收

- 状态：`未验收`。验收人 = 开发者；验法：
  1. 让女仆驾驶 AC-130H，一次引 3 个以上分散的敌人（保持多目标切换）。
  2. 日志搜 `模组坐骑·按住`：应能看到「目标在炮管背侧（固定炮）」「炮口前方 16 格内有方块」
     或「炮管与目标连线夹角 N°」，且都发生在开火之前。

     之间来回跳；「结束」里高差为正（先落地）的比例应显著下降。
  4. 单目标时的命中手感应与 1.3.3 之前一致；TNT 伤害不应变化。
