## 评估

- **载具不减速的根因**：绑定是**深拷**（`PatrolChartData.bind` 把航迹 `copy()` 进女仆的
  `persistentData`，之后两者各走各的）。玩家在航图里点「缓」只改了物品那一份，女仆身上
  仍是绑定那一刻的副本 → 运行时 `PatrolFlight.speedScale` 读不到减速点。扫帚那边当时能测出
  效果，应当是重新绑定过；载具没有重新绑定，所以完全没反应。
- **按下不立即生效**：同一根因（服务端只写了书），加上界面要等服务端回包/物品同步才刷新。
- **对齐**：标记管理页按钮从 `y=58` 起排，而文字行从 `72 + i*ROW_H + 5` 起画；两者固定差
  19 GUI 像素（截图上就是一整行的错位）。
- **直升机摇摆**：两处独立原因叠加。
  1. **俯仰太慢**：引擎的俯仰通道是 `xRot += 1.5 × 0.75 × mouseY × propeller`，propeller
     只有 0.09~0.12 → 鼠标 Y 打满 8 也只有 0.8°/拍。速度环要从"低头加速"翻到"抬头减速"
     得两秒多，速度总是晚半拍才收住，表现为沿航线来回摆、每次修正都拖很久。
  2. **横向没有阻尼**：纯追踪只瞄"投影点往前 L 格"，机身斜穿航线时仍带着横向动量；越线后
     要再等一个同样大的角度才拉回来，于是形成稳定的小幅来回。直写机头后还留了 mouseX 微调，
     而那条通道同时驱动滚转，升力被掰向侧面，又平添一份横向漂移。

## 改动

### 减速点即时同步（两树）

- `PatrolRoute.setSlow(int, boolean)`：直接设置某个下标的减速状态（供同步用）。
- `PatrolChartData.syncSlowToBound(server, routeId, idx, slow)`：遍历全服已加载女仆
  （`MaidRoster.inAsEntities`，与 `PatrolRevocation` 同一套），读身上绑定副本，id 相同就改
  对应下标、写回 `persistentData`，并 `PatrolFlight.forget`；返回实际改到几只。
- `PatrolNetworking` 的 `slowat`：写书后立刻同步，系统消息里回「已同步 N 只女仆」。

### 减速强度与范围（两树）

- `PatrolFlight.SLOW_SCALE`：0.25 → **0.1**；`SLOW_HALF`：4.0 → **5.0**（三轴各 ±5 = 10×10×10）。
- 范围框、文字标签、系统消息与界面提示同步改成 10×10×10 / 1/10。

### 标记管理页（两树）

- `marksButtons` 的行起点 `y = 58` → `72`：按钮顶边与文字行顶边重合。
- `toggleSlowAt`：先在客户端镜像上 `toggleSlow(idx)` 并 `rebuild()`（按下立刻变成琥珀色、
  行文字出现「慢」），再发 `slowat`；服务端回包后仍以物品数据为准。

### 直升机摇摆（两树）

- `MaidMountCompat.forcePitchOnto`：与 `forceHeadingOnto` 同一套后门，按每拍 3° 直接把
  `xRot` 写向目标前倾角；写成功就把 mouseY 归零（不让引擎再叠一层），写不到才退回原通道。
- `forceHeadingOnto` 成功后不再留 mouseX 微调（那条通道同时驱动滚转，会带来侧向漂移），
  改为归零。
- `PatrolCurve.Path.nearestNear`：投影点只在上一拍位置附近（前 40 / 后 80 个采样点）找；
  窗口内离得太远（>12 格，被吹飞/传送）才回到全局最近点——航线两段靠得近时胡萝卜不再跨段跳。
- `PatrolFlight.nextPoint`：飞行载具偏离航迹 >2 格时，前视从 8 格随偏离量收到 5 格（夹角更大、
  切回更快）；偏离 4 格内再按横向误差变化率给阻尼——正在回线时少打舵、正在离开时多打舵。

  `0CF9BDBE2418A941493B57FBCF3ECCFFD2C5CF781B017FE710E14761A3BA0DBE`。
- **反证**：
  - 同步只改 id 相同的那条绑定，不会碰到别的轨道；女仆没绑这条时 `readMaidRaw` 为 null，直接跳过。
  - `speedScale` 仍要求 `PatrolFlight.effective`（home + 扫帚/飞行载具 + 闭环）且未接敌。
  - 客户端先翻面只是界面镜像，服务端仍按物品真实状态写；写失败时下一次物品同步会覆盖回来。

  - 横向阻尼只在偏离 4 格内生效，且量被夹在 ±0.4×前视；远距离仍是全力切回。

## 边界

- 减速点对扫帚和飞行载具都是 **1/10**，范围 **10×10×10**；接敌、跟随、非巡逻一律不减速。
- 已加载女仆即时同步；未加载的要等加载后再点一次（绑定是快照，不做后台持久化推送）。
- 直升机俯仰直写每拍最多 3°，姿态仍然平滑；拿不到 `setXRot` 时自动退回鼠标通道。
- 局部投影窗口约 14 格后 / 28 格前；超出 12 格视为被吹飞，重新全局投影。
- 版本号仍为 **1.3.3**，同号重打；发布素材等验收后再写。
