## 根因与改动

### 1. 收完成品后不换台（`MaidCookBehavior`）

- **旧链路**：`doTick` 每 tick 先跑 `sweepNearbyOutputs`（5×5×5 内所有炉子的成品自动进包），再跑
  `processFurnace`。她干活时就站在绑定台旁边，绑定台永远落在这个 5×5×5 里——成品每 tick 先被 sweep
  收走，`processFurnace` 的成品槽永远是空的，于是 `tookOutputThisRound` 恒为假。
- **后果**：R1133 加的「收完成品那一轮不补料、交给 `rebindAfterCycle` 解绑重选」这道闸**一次也没触发**；
  她只会把同一台炉子的料烧到底。玩家在烧肉时旁边补一个烟熏炉，自然看不到转台。
- **修法**：`sweepNearbyOutputs` 跳过 `furnacePos` 本身——绑定台的成品只由按轮处理的 `processFurnace`
  去收（它才会置标志、才会刷新看门狗）。其余炉子的成品照旧自动进包，"路过别人家炉子不落成品"的行为不变。
- **效果**：收完成品 → 下一轮按 R1133 的规则重选台（烟熏炉 / 高炉优先、同级就近），新放的好炉子
  下一件就用上；正在烧的那件不打断、成品也不留在旧台。

### 2. 灰烬熔炉文案

- 实测暮色森林（Twilight Forest）没有叫「灰烬熔炉」的方块，原描述属于臆测举例。
- 删掉例子，只保留可验证的口径：「方块本身不是熔炉类、方块实体却继承原版熔炉的那一类」。
- 落点三处：`MaidSmartConfig` 字段注释、TOML `.comment(...)`、`PromaidConfigScreen` 的
  「熔炉等价族」悬浮提示；`isFurnaceFamilyBlock` 的说明同口径。
- **Neo 树同款文字未改**（按"不动 1.21.1"的指示保留原状；若以后要统一，一句话即可镜像）。

### 3. 巡逻航图爆内存（`PatrolPreviewClient`）

- **分配风暴**：世界预览是**每帧**渲染，旧版每帧 `PatrolChartData.readBook(stack)` 重新解析整本 NBT；
  再把书里**全部**轨道的**全部**标记都画出来（每颗菱形约 140 个临时 `Vec3`，外加每颗 1 个
  `float[]` 与 2 条标签字符串）。16 条 × 64 点 ≈ 1024 颗，60 帧下就是每秒几百万短期对象。
- **修法**：
  1. **书解析缓存**：按 `ItemStack` 引用 + 根 `CompoundTag` 引用做键，二者都没换就复用上一帧的
     `PatrolBook`；`clear()` / 退出登录时清空缓存。
  2. **标记裁剪**：选中 / 正在标记的那条不受限；其余轨道只画 64 格内的标记，且每帧总预算 96 颗。
  3. **配色静态化**：四个颜色数组提为常量，不再每颗 `new float[]`。
  4. **标签跟随实际绘制**：被裁掉的标记不再生成两条标签字符串，字符串数量随绘制数量有界。
- 远处的半格菱形在视觉上本来就是噪点，裁剪后观感不变；服务端巡逻 tick 另行核查过，无无界结构
  （`PatrolFlight.CACHE` 上限 256、预览 CACHE 上限 32、GOTO 有时限），本轮不动。

### 4. 排班表里打不开饰品栏（新增 Mixin + 3 秒宽限）

- **第一道门**：TLM 的页签按钮发 `OpenMaidGuiMessage(tabId)`，服务端 `stillValid` 要求
  `maid.distanceTo(player) < 5.0`。远程开界面时玩家通常站得很远，切页签的包被**静默丢弃**——
  界面还停在「女仆配置」。
- **第二道门**：切页签会先 `removed()` 掉当前容器，我们据此 `disable()` 收回远程授权；下一 tick
  新容器（Curios）的 `stillValid` 按 3 格判定，同样判死——即使包没丢，界面也会"一闪而过"。
- **修法**：
  1. 新增 `MaidGuiPacketRemoteMixin`，在 `OpenMaidGuiMessage.stillValid` 的 `RETURN` 处，若
     `RemoteMaidGui.isActive(player, maid)` 则放行；死亡 / 睡觉 / 换主人三条照旧否决。
  2. `RemoteMaidGui` 增加 `RECENT`：`disable()` 时把这一对记入 3 秒宽限；宽限期内 `isActive`
     命中就把会话接回（`opened = true`，泵只维持同步、不重复开界面），容器换页的缝隙被补上。
  3. `mixins.promaid.json` 注册新混入。
- 玩家自己右键开的界面不受影响（`isActive` 不成立），3 格距离照旧。
