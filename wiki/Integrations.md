# 软联动

武器判定遵循**原版属性**，因此任何带攻击力属性的模组武器都可直接参与自动装备、伤害结算与主动参战。

下列联动均以**反射**方式实现，属于可选内容；对未安装、版本不符或内部结构变更时，相关功能自动停用，不影响本模组的启动与其余功能。

## 模组联动内容

| 模组 | 联动内容 | 状态 |
|---|---|---|
| [TaCZ] 永恒枪械工坊 | 零枪械与弹药识别、弹种匹配，以及空袭与扫帚模式下持枪开火 | 完整 |
| [SBW] 卓越前线 | 枪械与弹药识别；坦克、装甲车、直升机、固定翼与飞艇的驾驶、炮塔瞄准、弹仓补给与飞行控制 | 完整 |
| [Goety] 诡厄巫法 | 以风系位移聚晶作为空中推进手段 | 不完善 |
| [IaF] 冰火传说 | 巨龙的骑乘与飞行操控，普通版与社区版均可 | 不完善 |
| [TWT] 口渴 | 女仆向主人喂水，效果与主人自行饮用等价，包含容器返还 | 完整 |
| [BD] 超越维度 | 女仆从主人的维度网络中存入与取出物品 | 不完善 |
| 万法皆通（车万女仆：万法皆通） | 女仆在空袭过程中释放法术 | 完整 |
| [EF] 史诗战斗 | 修正其女仆战斗任务的武器契约，使模组武器进入自动装备与主动参战判定 | 完整 |
| [YSM] 是，史蒂夫模型 | 模型共存，不会因渲染差异导致客户端崩溃 | 完整 |
| [Spear core] 长矛核心 | 长矛的相关战术及空袭优化 | 完整 |
| [Trials Chambers] 试炼密室 | 1.20.1 版本特有，重锤的相关战术及优化（1.21.1 本来就有，这个兼容只是为了让 1.20.1 玩家也能玩到重锤女仆） | 完整 |
| Curios | 饰品栏中的鞘翅可作为空袭的启动条件 | 完整 |

## 特别说明

- **傀儡装配**的傀儡师功能默认不在自主切换列表内（存在 bug）。
- 当女仆使用**拔刀剑**任务时，本模组的战术走位不生效——拔刀剑玩法自成一派，本模组的战术对其反而是累赘。
