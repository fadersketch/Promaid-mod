# Promaid（更智能的车万女仆）

为《车万女仆》(Touhou Little Maid, TLM) 制作的扩展模组，让女仆真正"活"起来——会建造、会干活、会记事儿、会说话，还会在危险时保你的命。

- **1.20.1 版**：Minecraft 1.20.1 · Forge 47.4.x · 前置 TLM ≥ 1.5.0（实测 1.5.3）· 版本 **v1.2.4**
- **1.21.1 版**：Minecraft 1.21.1 · NeoForge 21.1.250 · 前置 TLM ≥ 1.5.0（实测 1.5.3-neoforge）· 版本 **v1.2.4**
- **许可证**：MIT · **仓库**：github.com/fadersketch/Promaid-mod

**纯独立前置**：只要求原版车万女仆（TLM），不对任何其他模组做专属联动（曾经的第三方软联动已全部移除）。不过**武器判定基于原版攻击力属性**，所以 tacz / 卓越前线 / 拔刀剑 / 史诗战斗 / 万法皆通等模组的武器**天然可用**，无需专门适配。

> 开发过程中使用了 AI 辅助编程工具；作者并非专业程序员，代码中可能存在缺陷。开发者平时只玩单人模式，未针对多人服务器做优化，有此类问题请多加谅解，也欢迎到 Issues 反馈。

## 一句话看懂

Promaid 按「**要不要 AI**」分两大类功能：

- **不需要 LLM，配好就能用**：**空袭（会飞的女仆）+ 空袭轰炸**、**三叉戟激流旋转冲击**、建造执行、挖矿、伐木、烧制、酿造、农场、宰杀、战斗自保、**战斗模式分类表**、单兵战术、武器/工具自动切换、被动保命技能、**飞行跟随**、贴身辅助、**压缩盒**、感知播报、情绪、TTS 与**内置日语语音包**、排班调度、**指标石**、女仆管理；
- **需要先配 LLM 站点**：主动对话、工作播报、自主决策、AI 记忆、AI 工具（对话直接下命令）、LLM 现场生成蓝图、AI 设计器。

**进游戏就会收到一本《Promaid 手册》**（丢了用 `/give @p maid_smart:blueprint_book`，或工作台「书 + 纸」合成），里面有 33 章保姆式教学，每章先讲「是什么」再手把手教「怎么用」，关键步骤都配了【举例】。

### v1.2.4（本版）：三叉戟当燃料、精妙背包适配、守家模式两条修复

**新功能**：

- **激流三叉戟当「飞行推进剂」**：起飞、空袭的盘旋抬升与俯冲下扎、飞行跟随四条链路都能烧三叉戟；力度**照搬玩家在水里那一记**（`v ← v×0.5 + 视线 × 原版力度`）并按附魔等级放大，再补上玩家那份空气阻力（水平 ×0.92/tick），行程回到玩家的量级（I / II / III ≈ **17 / 25 / 33 格**）；取材范围主手 → 副手 → 背包，耐久扣在真正用到的那一件上；飞行跟随另加省料开关 `flightFollow.trident`；
- **精妙背包 / 旅行者背包适配**：她自己的背包满了，多出来的那一份**装进身上那件「额外容器」**（[issue #20](https://github.com/fadersketch/Promaid-mod/issues/20) 报的农场连锁收割掉落落地就是这一处）；反过来取料时也先去那里面找。走 TLM 自己的容器 API，不反射第三方模组。

**修复**：

- **守家（home）模式下农场女仆「在田里到处乱转」**（[issue #22](https://github.com/fadersketch/Promaid-mod/issues/22) 第一条）：我们给守家女仆写的"随机巡逻"每 0.25 秒改一次导航目标，**覆盖掉了原版农场任务正在走的路径**；现在**农场完全交回原版**（平常站着/散步，作物成熟了才走过去收），锄地也不再抢路；
- **打完怪「驻守」变成「跟随」、回不去**（issue #22 第二条）：战后还原把"战斗前模式快照"**删在了读取之前**，`getBoolean` 读不到就返回 `false` → 每打一场架都把守家关掉。现在**先还原后清标记**，且**没有快照就完全不动她的设置**；
- **「我卡住了，快喘不过气了」不再当口头禅**：原来只要"头部那一格形状够实"就喊，一点血没掉也喊；现在**只有真吃到超过 4 点窒息伤害**（原版 `in_wall`，5 秒窗口累计）才说，自救动作照旧，说与不说都有运行日志可查；
- **右键蛋糕崩服（1.21.1 专属）**：移植时把"蛋糕可食用"注错了方法，改用 1.21.1 的数据组件挂 `FOOD`；
- **远程空袭「拿着枪一枪不放」**（两处病根 + 新增「远程开火」诊断行）、**烧制 / 酿造没有目标时不再把自己冻在原地**、**骑乘或坐下时禁止搭方块**（护栏统一到全部搭方块行为）。

**口径变化**：**压缩盒里的带附魔物品一律禁入**——「禁入带附魔的物品」开关与「禁入清单」两个配置项**已删除**（详见下面压缩盒那一节）。

### v1.2.3 加急修复：收放魂符不再丢血量上限与装备

**症状**（B 站用户 lawte 与 GitHub [issue #18](https://github.com/fadersketch/Promaid-mod/issues/18) 的 P1aneZ 都反馈过）：

1. 好感度升阶给女仆带来的**血量上限加成**（比如 80），在**收放魂符之后会掉回 20**，反复横跳；
2. 收放魂符之后，从她的背包或装备栏里**往外拖东西，第一件会直接消失**（不在你背包、也不在她身上）。

**根因不在 TLM，也不在服务端**——她存档里一直是好的（TLM 收放魂符就是「拍快照 → 放出来时读回」，血量上限与装备都无损）。坏在**本模组自己的「入世界自动补包」**：它为了治「客户端看不到她」（下面那一节）而在女仆每次入世界时补一发**删实体 + 重新生成**，而**收放魂符的「放出」本身就是一次入世界**——于是每收放一次，客户端那只女仆就被销毁重建一次：新实体没有属性表（上限就是默认的 20），而你正开着的物品栏抓的还是**已经被删掉的那只实体**，拖进去的东西就落进了虚空。

**v1.2.3 的改法**：补包改成**按实体网络 id 分流**——魂符放出的**新实体不再补包**（原版追踪本来就会发全套：生成 + 数据 + 属性 + 装备），只有**同一只女仆离场又回来**（区块卸载重载这类、id 没变）才补；补的时候顺带补发一次饰品全量同步。另外新增一条诊断：她的装备槽**从有东西变空**时会写一行日志（`logs/promaid.log` 搜「装备离开」，含槽位、丢了什么、她背包实时快照与调用栈）。

> 顺带修掉的另一条同类反馈（[issue #17](https://github.com/fadersketch/Promaid-mod/issues/17)）：女仆着火时会把背包里的金苹果**连着吃到背包空**——原因是那条冷却对「会被消耗的普通食物」从来没生效过。现在金苹果/附魔金苹果吃完会按**它自己给的效果时长**记一次冷却（普通 = 吸收 2 分钟，附魔 = 抗性/抗火 5 分钟），一次一颗、吸收耗尽才会再吃。

### 空袭 —— 会飞的女仆（v1.2.0 主线）

从零做了**两个飞行攻击模式**，本版近 40 条改动都在打磨它。给女仆穿上**鞘翅**、带上**武器**和**可以飞行的道具**（**烟花火箭 / 孔雀羽扇 / 能上天的位移类法术**任一），她自己飞起来打怪——不再贴地追着砍。**装备不齐她不会飞**，而且切到任务当场就报缺哪一件（缺飞行手段时气泡只说「没有可以飞行的道具」）。

| 模式 | 怎么打 | 武器位 |
|---|---|---|
| **近战空袭** | 爬到敌人上方 → 收翅俯冲 → 触底前一记近战 → 再起飞，循环 | 任意近战武器（剑/斧/三叉戟/重锤/模组近战） |
| **远程空袭** | 在天上**盘旋**并用手里的远程武器持续开火 | 任意远程武器（弓/弩/御币/三叉戟/模组弹射/枪械） |

- **三件套**：鞘翅（切任务后她自己穿到胸甲槽）+ 武器 + **可以飞行的道具**（烟花火箭 / 暮色森林孔雀羽扇 / 位移类法术，放背包就行）；远程空袭额外需要弹药，御币/三叉戟不消耗弹药；**不响应自主切换**（不会被"主动参战"改任务、也不会自己换掉你给的武器）；
- **收翅俯冲那一击**：1.21.1 手持**重锤**时按玩家同款的**重锤下落加成**结算（还有风爆的原地爆炸 + 自我顶起），而且她按**本轮最高点**算落差——**飞得越高这一锤越狠，不设上限**；其它武器按原版**暴击 ×1.5** + 附魔。命中率有三道保险（判定距离 4 格 / 收翅 2 tick 即可出手 / 对身边 2.5 格内其他合法敌对目标补一记，女仆一律跳过、**绝不误伤主人与宠物**，且要过视线）；
- **远程空袭**：绕目标约 10 格盘旋、**维持在目标上方 10 格**（实测五百七十九 从 3.5 提高：3.5 格太薄，滑翔一转弯就低于敌人）；**掉出高度带 0.5 格就补推**（烟花/羽扇/位移类法术任一，法术优先——不消耗燃料，不是无脑烧）；怪物贴到 3 格内时**弹开她自己**（只弹她不弹怪，狭小空间里敌人仍有机会命中）；开火走 TLM 自己的通道，附魔照常生效，御币的扇形分档规则照搬原版（单挑单发 / 3~5 只同种怪 8 发扇形 / 超过 5 只 32 发大扇形），装了 TACZ / 卓越前线的女仆能**拿枪在空中开火**；弩还能射**攻击性烟花**（带烟火之星的那种）当弹药——**普通烟花默认不烧**（原版任何版本里它都是 0 伤害，白烧一枚飞行燃料），想按原版玩家口径把普通烟花也当弹药可在面板里开；
- **索敌**：以她自己为圆心、**半径 50 格的球**，**锁定即持续瞄准**——不再走 TLM"按排班活动决定扫描盒"那套（旧机制在她飞高后会因扫描盒只有 4 格高而丢目标、在空中飘走）；视线只作为**新锁定**的门槛，"隔墙不出手"依然成立；
- **空袭牵引绳**（新增）：空袭期间以她为圆心、半径 **100 格**（可调，0 = 关闭）内找不到主人，就**立刻把她传送回你身边**——与排班表那次人工传送同一条链路（强制生效、无视地块、可以空中传送）。防的是"她飞太高把目标打死后自己回不来"；距离按 3D 算，飞太高本身也会触发；
- **空袭途中顺带放法术**（需装《车万女仆：万法皆通》touhou_little_maid_spell）：飞行武器照打（近战空袭照样俯冲砸、远程空袭照样盘旋射），法术书放**背包或饰品栏**就顺手把法术也放了——法术模组自己会扫她的背包与饰品栏，**不看主手**，所以不占武器位；**放哪个法术由它决定**（从她的法术书里随机挑一个不在冷却、不在黑名单的），**女仆没有法力条**，只受冷却限制；只在"**本来就对着目标**"的两段发起（远程在盘旋开火前、近战在已爬到目标上方准备俯冲时）——法术吟唱期间会把她的朝向拧向目标，而鞘翅是顺着视线飞的，爬到一半被掰朝向会毁了这一轮；**爬升段与收翅俯冲那一记刻意不施法**。三个开关在「单兵战术」：空袭顺带施法（默认开）/ 空袭施法间隔（默认 20 tick）/ 空袭施法距离（默认 24 格）。
- **位移类法术当推进器**（需装《车万女仆：万法皆通》+ 位移类法术）：空袭把位移法术当成**和烟花同一套口径**的推进器——**同一触发（掉出盘旋高度带）、同一朝向（起飞/补高照抄烟花起飞那套：地面目标背离+抬头、目标高 10 格以上朝目标+抬头；盘旋里用烟花掉高窗口那 45° 抬头）、同一窗口（法术成功时自己开那个抬头窗口，所以只带法术不带烟花也进得来）**，而且**优先于烟花/羽扇**——不消耗燃料、也不占烟花冷却。两张表：**提供高度**（默认【升腾】`irons_spellbooks:ascension`＋【烈焰冲锋】`irons_spellbooks:burning_dash`）用于**平地起飞 / 空中补高 / 盘旋续航**，**提供速度**（默认【烈焰冲锋】）在掉高窗口里补速度（窗口外不放，免得她从盘旋圈上切进去）。两条必须知道的口径：① 烈焰冲锋的冲量是 `normalize(视线×(3,1,3))+(0,0.25,0)` 再乘 `(15+法强)/12`——**水平被放大 3 倍**，所以「抬头 62°」的实际轨迹约 45°；且它是**一次性冲量**（向冲量插值 75%）不是烟花的持续推力，**持续爬升靠升腾那 4 秒悬浮**（重力×0.15），高速滑翔时那一口甚至可能削速；② 盘旋掉高的补推阈值已修（旧版 3.0 与期望高度 3.5 相消 = 必须几乎贴地才补，所以「低于期望高度就补」从来没生效过、每次都是掉地上再补）——现在比高度带低半格就补。另有「位移法术间隔」（默认 40 tick）与「尊重法术自身冷却」（默认开，只管「提供速度」那一类；起飞/补高从不看它）。日志搜「空袭·位移」（起飞/补高/冲刺）与「掉高·位移法术顶高度」（盘旋续航）。
- **空袭期间的传送口径**：**自动**传送一律让位（跟随拉回 / 跨维跟随 / 「搭太高」拉回 / 自保归位），但让位有界——持续滞空超过 15 秒就强制拉回（防「飞太高打完回不来」），落地即清零；**玩家手动「⚑ 一键集合」与主人死亡传送照常生效**（人工/紧急意图优先），另有上面那条「空袭牵引绳」也会把她捞回来、不触发自保（但**不免疫真实伤害**，照样会被打下来）、滑翔/悬空/俯冲时不搭方块、落地自己放水/细雪接住；
- **默认开着「空袭免疫摔落伤害」**：空袭整条链路是"高空盘旋 + 收翅俯冲"，落地缓冲万一没接住（背包没桶/落点被占/被打断）代价是十几点伤害甚至摔死——想按原版吃摔伤可在「生存与复活 → 落地缓冲」里关掉。

**空袭轰炸 —— 打完了顺手放炸弹（v1.2.2）**

近战空袭打完那一记、远程空袭开火之后，她会**顺手放一枚炸弹**，然后再继续下一轮。四条链路各走各的，**材料齐的几段在同一次攻击里都放**：

- **末地水晶**：黑曜石底座 + 末地水晶（成品按原样留在场上，起爆后底座还给她）；**重生锚**：要 1 颗**萤石**（方块，不是萤石粉）充能；**床**：只在原版真的会爆炸的维度放（维度闸，默认开）；**投掷 TNT**：挂在攻击链路最末段，**所有有战斗标签的模式**都会扔（近战/弓弩/三叉戟/弹幕/枪械/两种空袭），需要同时有 TNT 与**点火料**（打火石——按**类**认，走耐久；或烈焰弹——消耗品）。TNT 的判据很宽：**注册名里带 tnt 的都算**，方块**继承原版 TntBlock 的也算**（各模组的 TNT 都认），而且放出去的就是**它自己那一枚**；
- **默认全部保护**：「轰炸破坏方块」默认**关**（只炸伤害与击退、不动地形，**模组 TNT 也归这条管**）；「轰炸伤到主人/友军」默认**关**（主人与同主女仆不掉血也不被震）；爆炸火焰改成**粉色火焰**（不蔓延、会自己灭，**玩家与女仆都不被它点燃、不掉血**）；她做这些事时**副手会举起正在用的那一件**（萤石 / 打火石），看得出在干什么；
- **远程空袭也放**，而且目标悬空时走"后门"（落点直接取目标头顶那一格，不要求支撑面）；她带着材料却没放，`logs/promaid.log` 搜「轰炸跳过」会写明原因。开关都在「战斗与自保 → 空袭数值 → ⑦ 空袭轰炸」。

**空袭 34 项数值全部可调（v1.2.2）**：起飞段时长与仰角、起飞触发距离、占位高度容差、烟花/羽扇间隔、收翅俯冲距离、猛击命中判定半径、盘旋半径与期望高度、掉高容差与补推窗口、开火间隔与射程、近身弹开参数、俯冲段冲刺加速……原本写死在代码里的数值**全部搬进配置面板**（「战斗与自保 → 空袭数值」，七小节），**默认值与原硬编码一字未改**，改完立即生效。

**索敌口径（v1.2.3 两处调整）**：

- **隔着方块的怪不再算威胁**（v1.2.3）：以前她会"感知"到地下空洞里、墙那头的怪并写进攻击目标，找不到入口就**原地打转**——因为原版对"已经是攻击目标的实体"会**跳过视线判定**，下游所有链路（TLM 的追击、挥刀）都当它看得见。现在威胁候选**加了一道视线门**（与原版同口径），被方块挡住的怪**根本不会进目标列表**，"隔墙挥刀"也从源头断了；

### 女仆"看不见了"？—— 客户端实体丢失的自救（v1.2.2）

**症状**：她**还在干活**（方块在动、怪在掉血、`/tp` 找得到她），但**看不到模型**、
按 **F3+B 也没有碰撞箱**——这是**客户端实体丢失**：服务端一切正常，只是客户端那侧没有这个实体。

**为什么会这样**：法术模组（touhou_little_maid_spell）在女仆"离开世界"（区块卸载 / 维度切换等）时会发一个
包**让客户端删掉她的实体**；而它自己给客户端补回实体的链路只对带"锚核"的女仆生效——
没带锚核的女仆被删掉后、随后又被加回同一个 level 时，原版追踪表未必再发一次生成包，
于是"服务端好好的、客户端永远没有她"，**直到重登游戏**。

**处理**（游戏内执行，需 OP / 单人作弊）：

```
/maid_smart resync          # 你名下的女仆
/maid_smart resync all      # 全服所有女仆
/maid_smart resync <UUID>   # 指定女仆（跨维度也能找到）
```

命令会打印每只女仆的**维度 / 坐标**（顺带用反射问 Sable"她是否被判在 sub-level 内"，
用于排除追踪位置误判），并对**同维度的主人客户端**强制补一次实体包——通常**当场恢复可见**；
若无效，**退出重进游戏一定恢复**。本模组还会在女仆**离场 / 入世界**时自动补包，
过程写进 `logs/promaid.log`（搜「离场」「重同步」）。

> 另外两条相关的健壮性修复：**空袭召回超时兜底**（她被困在远处/异维度时，
> 空中让位不再"永久禁传"——超过 15 秒即强制拉回）与 **Sable 兼容**
> （全图扫描不再被 Sable 拒查，详见 CHANGELOG 实测五百六十三/五百六十四/五百六十五）。

- **环境伤害软处理**（v1.1.0 新口径）：踩仙人掌/轻微摔伤等小伤害不再触发整套逃跑，脱离危险源后原地休整回血；真正的持续威胁仍按完整自保处理；
- **主动切换战斗**（v1.1.0，默认开）：你被有来源的攻击打（怪物/玩家/弹射物）或攻击敌对生物时，附近 16 格内女仆无论干什么都立即切战斗来保护你，威胁消失约 10 秒后自动还原原任务；选战斗模式时扫描背包所有攻击类任务，**背包里有模组武器必定切它专属的战斗模式**（拔刀剑→拔刀剑模式、史诗战斗→战斗模式），敌人远选远程、近身选近战，战中还会动态换战术；
- **战斗模式分类表**（v1.2.3，新）：上面那套规则原本三条全是写死的——**谁能进候选池**、**算近战还是远程**（靠 UID 关键词与命名空间**猜**，未知模组任务一律当近战兜底）、**池里有模组专属任务时原版五件套整体让位**（"模组优先"）。装了冷门模组的人只能看着远程任务被当近战冲脸、看着某个模式被整体挤掉，面板里一个字都改不了。现在可以**逐任务点名**：配置 `combat.taskModes` 一行一条 `任务UID=近战/远程/不参与`（认中文写法与逗号分隔）——写 `近战`/`远程` = **分类以表为准**，而且这个任务**不再被"模组优先让位"挤掉**（你点名的优先）；写 `不参与` = **入战选任务与战中换战术两条路都永不选它**（想让它只在你手动指派时上场就用这档）；**留空 = 与旧版一字不差**。不想用"模组优先"就关掉新开关 `combat.vanillaYieldToMod`（默认开 = 旧行为；关 = 原版与模组同池纯按权重随机）。查 UID 用只读命令 **`/maid_smart combat modes`**（把当前所有攻击类任务列成"内置算什么 ｜ 现在算什么 ｜ 表里写了什么 ｜ 参不参与"，抄一行改一改就是表项）；面板位置「战斗与自保 → 主动参战」；
- **法术任务的"她会用法术吗"闸门**（v1.2.4，修反馈）：《车万女仆：万法皆通》的法术任务（近战法术 / 远程法术）自己的武器判据是"什么都能当武器"，所以自主战斗这边单独收紧——**她得真的带着法术装备**才允许被自动切过去。而"法术装备"的定义是那个附属交给各前置附属自己的 provider 的，javap 反编译看其中**两条认的"法术装备"本身就是武器**：`slashblade` 认**拔刀剑**、`youkaishomecoming` 认**弹幕/激光/符卡**（它们在 TLM 侧各自已有专属战斗模式）。旧口径等于"背包里有把拔刀剑 = 她带着法术书"→ 法术任务进候选池 → "模组优先让位"再把原版任务挤掉 → 只给了刀的女仆被自动切去法术模式（实测三百七十九 同款反馈的第二次）。现在新增配置 `combat.spellGearIgnore`（默认 `slashblade, youkaishomecoming`）把这些 provider 排除在"她会用法术"之外，面板位置「战斗与自保 → 主动参战 → 法术装备忽略表」，**留空 = 旧口径**。排查：`latest.log` 搜 `combat pools`，池里有法术任务时会附 `spellGear=` 直接点名是哪件东西放行的。**注意**：TLM 面板里那两项任务**永远显示**（附属的 `isEnable` 恒返回 true），与本模组无关——本模组从不拦你手动切换任务；

- **激流三叉戟旋转冲击**（v1.2.0）：详见下面「三叉戟」一节。

### 三叉戟：近战 / 远程 / 激流旋转冲击（v1.2.0 重做）

三叉戟在本模组里有三条明确分工，**近战与空袭两条线都能用**：

- **当近战武器**：攻击模式 / 近战空袭都认它（原版三叉戟的近战伤害与附魔照常结算）；三叉戟的武器归类按"近战武器"走，所以她在攻击模式下会拿它贴脸打，不会站着原地转圈；
- **当远程武器**：远程空袭里它能投掷，而且**不消耗弹药**（免检，不会误报"缺弹药"）。注意**附了激流就投不出去**——那是原版"水里突进"的设定；
- **激流旋转冲击**（默认开，可在配置面板关掉）：主手拿着**带激流附魔的三叉戟**时，她那一记普通挥砍会被**替换成旋转冲击**——也就是把玩家那套"激流突进"搬成了女仆的**独立攻击链路**：
  - **触发就是她的攻击时机**：近身 **4 格**内替换（地面要站在地上）；空袭的**收翅俯冲那一记在空中也替换**（那一下本来就在空中，实战价值更大），**空中旋转期间不会自我摔伤**；起不了手就照常挥砍；
  - 旋转 **16 tick**，与玩家同款（平躺 + 高速自转），撞到谁就结算一次伤害（攻击力 + 附魔），**同一目标每次突进只打一下**；
  - 原来那一记普通挥砍由这条链路**取代**（走路、索敌、排班一律不变）；关掉「激流三叉戟旋转冲击」即恢复普通三叉戟挥砍；
  - 视觉上照抄了官方那圈"激流特效"（是个独立的渲染图层），旋转枢轴也抬高过——不会看起来像嵌进地里。

### 主人免伤（三层防护）

女仆**绝不伤害主人与同主女仆**——这是针对实测 bug（带女仆到雪地打雪仗后，她会对主人跳劈）的专门加固：

1. **伤害事件总闸**：女仆造成的主人/友方伤害在攻击/受伤/结算三处直接取消；
2. **全部攻击注入点过滤**：战术跳劈、近战横扫、中立威胁反击、自保反击（含弹幕/射箭）、LLM 攻击工具，目标为主人/友方时一律不执行；
3. **定期清除仇恨**：每 2 秒把主人/友方从 `ATTACK_TARGET`、实体目标、复仇目标里清掉。

结果：雪地打雪仗只会扔雪球，**绝不会对主人挥刀**；同主人的女仆之间也互不误伤。

### 单兵战术 / 贴身辅助 / 武器切换

- **单兵战术**（PVP 式走位，默认开）：近战贴脸绕圈侧移 + 打一刀退一步 + 跳劈（剑单敌 100% 空中暴击）；远程保持理想射程放风筝 + 横移绕圈；攻击冷却间隙举盾格挡、冷却满放盾攻击；装上 TACZ/卓越前线时枪械任务全套战术照常生效；
- **贴身辅助**：你饱食度低时自动投喂（有音效 + 系统消息）、自动治疗、战斗任务下自动配盾。**投喂不再只认原版食物**（v1.2.0）：判定改为「有食物属性 + 不在黑名单」（与 TLM 自己"女仆饿了吃"完全同口径），三明治 / 模组料理 / 模组水果全都认；默认不喂腐肉、蜘蛛眼、毒马铃薯、河豚、紫颂果、可疑炖菜、各种生肉生鱼，以及金苹果/附魔金苹果（留着走"治疗链"）。配置面板里是**勾选面板**（`战斗与自保 → 贴身辅助 → 投喂食物勾选`）：列出全部带食物属性的物品，点图标切换能不能吃（绿框 ✔ / 红框 ✖），支持搜索翻页，底部实时显示"共 X 种食物，当前可喂 Y 种"；
- **女仆支援喂食 = 她自己吃**（v1.2.0）：喂给另一个女仆的食物，回血量与她**自己吃逐行同源**（此前投喂走的是原版 `eat()`，漏掉了 TLM 餐食系统里那一记"吃食物回血"——一根胡萝卜实际少回 1.32 点）。金苹果那条刻意不补（她自己吃金苹果同样只走 `eat()`）；
- **武器与工具自动切换**：干活/战斗前自动换最合适的工具——近战武器按 **DPS（最终伤害 × 攻速）> 附魔词条 > 剩余耐久**评分；挖矿发现目标矿才换合适的镐；伐木自动换斧；剪刀任务自动拿剪刀（认 `forge:shears` 标签的模组剪刀）；盾牌爆了自动补；只剩 ≤10% 耐久才拉黑，主手快坏会提前换下一把。**判定全部基于原版属性系统，没有任何武器黑名单**——其他模组的武器只要带攻击力属性就正常使用。

### 被动技能（独立板块）

不用切任何任务，任何状态下都生效：

- **落地水**（默认开）：背包有水桶时坠落超过阈值（默认 4 格）自动放水缓冲，水桶不消耗、落地后收回；**落地雪**（默认开）：有细雪桶时在落点铺 1×1 雪垫接住自己（下界也能用，水会蒸发、细雪不会）——v1.2.0 起落地雪有了**自己的三项数值**（触发高度 4 格 / 保持 5 tick / 下探 2 格），与落地水各读各值；两者都有时**优先用水**（水会流动自己铺开，细雪不流动、容错只有一格）；
- **岩浆逃生放水**：垫高自救后周围没水源且包里有水桶，就地放水灭火（1 秒后收回）；
- **主人死亡传送**：主人死亡时无视距离强制传送到重生点（床/重生锚，跨维度通用）；home 看家/坐着/骑乘中的女仆保持原位；
- **搭路**（v1.1.0，默认关）：背包有可放置方块且周围无敌对生物时，只要与你隔沟/隔空就朝你方向铺方块并踩上去一路接近（平地跟踪距离无上限，像僵尸搭桥追人）；你远高于她时垫方块搭高靠近；垫的方块会自动回收，不破坏地形；挂着战斗任务但没在真打时也照常搭路，**一旦接战立即停搭转入战斗**；
- **飞行跟随**（v1.2.2，**默认关**，观赏玩法）：你自己飞走了（鞘翅），她也能**背上鞘翅追过来**——触发条件与搭路同一档（本来要搭路追你的场合），**起手 25 格 / 收手 5 格是两个不同的球**（3~128 可调，中间 20 格迟滞，免得在边界上反复起落）；进到收手半径里会**解除烟花给的推进矢量**再交回普通跟随；燃料可以是**烟花火箭 / 孔雀羽扇 / 能上天的位移类法术**（任一，法术优先、不烧燃料）；两个空袭任务**未接敌**时同样适用；配置在「移动与行为 → 飞行跟随」，`/maid_smart flyfollow` 是它的调试入口（`elytra_goto <x> <y> <z>` 能让她飞去指定坐标——这一件取自粉丝 Roderick32 的「鞘翅赶路」分支）。

### AI 记忆系统

女仆会把重要的事**记下来**，下次对话还记得——这是她「有人味」的核心（需 LLM）。

- **记什么**：重要事实段落、关系三元组（主人-喜欢-红茶）、主人画像、工作笔记；
- **怎么记**：对话积累到阈值（默认 10 条）LLM 自动提取、她主动调用 `remember` 工具、感知/情绪系统写入；
- **记忆日记**（多级索引）：把每天的事写成第一人称日记——日/3日/周/月四级，跨度越大压缩越狠；可用 `query_memory_index` 翻旧日记回答「上个月我们做了什么」；
- **睡一觉自动整理**：全员真实睡过夜后生成当日日记，并把够重要的记忆**沉淀为长期**（不再随时间淡忘）；服务器上玩家登出也算一天结束；
- **人格种子**：每只女仆独立的人设文件，与聊天记忆分离，聊天不改写人格；**情绪快照**：每条新记忆附带当时的 PAD 情绪；
- **链路调试**：手册「女仆记忆」页可对单条记忆上调/下调重要度、标记删除、恢复、强化；
- **遗忘**：记忆按衰减周期（默认 7 天）慢慢淡出，重要度高的保留。

### 主动对话 / 工作播报 / 自主决策

女仆会**自己开口说话**（气泡 + TTS），不用你先搭话（需 LLM）：

- **主动对话**：关心你重伤、夜晚困倦、好感升级、长时间沉默找话题；日上限与冷却可调；击杀邀功默认关（想听可在面板打开）；
- **工作播报**：干活卡住时用气泡解释原因（缺什么料/够不到/被挡路）；
- **自主决策**（必须 LLM）：空闲 + 白天 + 主人在 16 格内时，她**自己判断该干什么**并换任务（去种地/去挖矿），默认 10 分钟冷却、日上限 10 次；
- **回复反馈学习**：你说「别说了/好烦」她记住不再提该话题；说「谢谢」强化记忆；还会记录你多久没理她；

### 女仆安全与区块保载

所有有主女仆所在区块**持续保持加载**（停放的女仆周边农场/熔炉照常运转，也随时可被集合/召回/救援找到）；寻路会**主动绕开危险方块**（岩浆/火/仙人掌等，默认 9 种可自行添加模组方块），站在危险格上时自动挪到最近安全格并灭火，搭方块绝不垫这些方块；被困下界基岩顶层或掉出世界底部时自动救援传回。

## 安装

1. 安装对应版本的 Minecraft / 加载器（1.20.1 + Forge 47.4.x，或 1.21.1 + NeoForge 21.1.250）；
2. 安装前置《车万女仆》TLM（1.20.1 用 Forge 版，1.21.1 用 NeoForge 版）；
3. 把 `promaid-*.jar` 放入 `mods` 文件夹（**必须在游戏完全退出后替换**——运行中换 jar 会让 ModLauncher 按旧偏移读到坏数据，表现为加载阶段莫名崩掉）；
4. 进游戏拿手册；想用 AI 功能（对话/记忆/工具/自主决策），先按手册第 3 章把 OpenAI 兼容 API 站点配好。

## 与其他模组共存

- **「是，史蒂夫模型」(YSM)**：**不会崩**——v1.2.0（实测五百四十八）修掉了导致**黑屏进不去游戏**的 `ClassCastException`（TLM 检测到 YSM 会把女仆交给 YSM 渲染器，而我们的鞘翅图层把渲染器类型写死成了 Gecko 的）。但要注意：**鞘翅与激流旋转特效在 YSM 模型上不会绘制**——YSM 模型没有 Gecko 骨骼表，硬画只会把翅膀堆在原点，所以那两个图层在 YSM 渲染器下主动跳过；女仆的背部物品/鞘翅由 TLM 自己的 YSM 图层负责。1.20.1 与 1.21.1 同步修复；
- **其他模组武器**：武器判定基于原版攻击力属性，tacz / 卓越前线 / 拔刀剑 / 史诗战斗 / 万法皆通等模组武器天然可用，无需专门适配（本模组不对任何模组做专属联动）。
