# Promaid（更智能的车万女仆）

为《车万女仆》(Touhou Little Maid, TLM) 制作的扩展模组，让女仆真正"活"起来：自主建造、LLM AI 对话、长期记忆、战斗自保、自动装备与工具、排班日程……

**纯独立前置**：只要求原版车万女仆（TLM），不再依赖任何其他模组（旧版的第三方软联动已全部移除）。

- **1.20.1 版**：Minecraft 1.20.1 · Forge 47.4.x · 前置 TLM ≥ 1.5.0（实测 1.5.3）· 版本 **v1.1.0**
- **1.21.1 版**：Minecraft 1.21.1 · NeoForge 21.1.250 · 前置 TLM ≥ 1.5.0（实测 1.5.3-neoforge）· 版本 **v1.1.0-beta.2**（beta）
- **许可证**：MIT · **仓库**：github.com/fadersketch/Promaid-mod

> 开发过程中使用了 AI 辅助编程工具；作者并非专业程序员，代码中可能存在缺陷；开发者平时只玩单人模式，专用服务器适配有限，遇到问题欢迎反馈。

## 核心特性

### 排班表（日程系统）
给女仆排「几点到几点干什么」，到点自动切换工作模式/任务；支持早班/晚班/全天班次、在家模式一键调控、整页任务选择器、**当前时段整行高亮**；排班期间任务锁定（想改先关排班）；排名随女仆存档持久化，重启继续。

### 自主战斗与自保（单兵战术）
- **自主参战**：女仆被打、主人被打自动参战，打完自动还原原任务与模式；
- **单兵战术**：绕圈走位、打退拉扯、距离控制、时机举盾；剑单敌 100% 跳劈暴击（玩家式暴击结算：攻击力 ×1.5 + 附魔），群敌改横扫；
- **自保行为**：低血回血链（增益药水→治疗药水→金苹果→食物）、搭方块避险、传送回主人、水桶垫水、岩浆逃生、窒息/溺水自救；环境伤害软处理（脱离危险源后原地回血，不乱跑）；
- **被动技能**：落地水、岩浆放水、主人死亡传送、**自动回魂符**（受到致命伤害瞬间收回魂符，释放后冷却从释放时刻重新起算，收符提示带当前 CD 秒数）；
- **主人免伤（三层防护）**：女仆绝不伤害主人与同主女仆——伤害事件总闸取消、全部攻击注入点过滤、定期清除仇恨（ATTACK_TARGET/实体目标/复仇目标）。雪地打雪仗只会扔雪球，不会对主人挥刀。

### 建造系统
- **Promaid 手册（蓝图书）**：书 + 纸合成，建造目录显示导入/生成的外部蓝图（`config/maid_smart/blueprints/` 或存档 `schematics/`，支持 `.schem/.litematic/.nbt/.snbt/.json`），女仆自动施工；
- **LLM 现场生成 / AI 设计器**：对话下达「造一个 5x5 现代小屋」直接出蓝图；
- **工头模式**：一区块一工头，缺料/跳过/完成统一汇报；
- **建造 HUD + 进度持久化**：实时速度与预计完成时间，计划随女仆存档；
- **缺料自动替代**（同族→自定义）、**机械蓝图**（自动熔炉组等）、区块冻结防崩溃、极速模式、强制加载配额兜底。

### LLM AI 女仆
- 接入任意 **OpenAI 兼容 API**，女仆获得 20+ 工具：挖矿、整理、烹饪、酿造、建造、给物品、移动、拾取、查询记忆、感知环境、查看主人背包……；
- **主动对话 / 工作播报 / 自主决策**：主动汇报、提醒危险、表达情绪；空闲时自己判断该干什么；
- **长期记忆**：段落 / 关系三元组 / 主人画像 / 工作笔记 / 多级记忆日记（日/3日/周/月），跨会话保留，睡一觉自动整理；
- **情绪感知 / 回复反馈学习 / API 配额管理**；对话语言可强制（默认中文）。

### 任务与生产
自动挖矿（矿表白名单/连锁采集）、伐木（连锁砍伐+补种）、农场（连锁收获/批量种植/自动锄地/骨粉催熟）、烹饪（自动选炉不抢）、酿造（药剂手册：批量/定向酿造）、宰杀（超阈值自动宰杀）、钓鱼自动坐椅、搭路（被动技能化：战斗空闲也会铺路垫高，接战即停）。

### 交互与其它
摸摸头/抱抱（G/H）、蛋糕互动、女仆互助（喂药/喂食）、落地雪、手持光源发实光、宠物保护、拾取优先级、跨维度跟随、TTS 系统语音与语音包、聊天气泡上限；**全部功能游戏内配置面板逐项开关**（爱憎分明/heartfelt 联动板块已随软联动移除）。

### 内置手册
游戏内 Promaid 手册内置 **25 章保姆式教学**（每章先讲「是什么」再手把手教「怎么用」，关键步骤配【举例】）+ 完整逐版本更新日志。

## 专用服务器兼容

v1.1.0 起已修复两个服务端崩溃（粉丝反馈）：
1. 主类内联配置界面 lambda 触发 `RuntimeDistCleaner` 拦截 → 客户端类型签名全部移入客户端专类；
2. 主动对话调用 TLM 客户端专用方法 `ChatClientInfo.fromMaid` → 改为服务端安全构造。

> 说明：开发者平时只玩单人模式，服务器适配有限；若服务器上遇到其他问题，欢迎到 Issues 反馈。

## 安装

1. 安装对应版本的 Minecraft / 加载器（1.20.1 + Forge 47.4.x，或 1.21.1 + NeoForge 21.1.250）；
2. 安装前置《车万女仆》TLM（1.20.1 用 Forge 版，1.21.1 用 NeoForge 版）；
3. 把 `promaid-*.jar` 放入 `mods` 文件夹；
4. （可选）AI 对话：游戏内 TLM 面板 → 模组详细配置 → 填 OpenAI 兼容 API 地址与密钥。

完整逐版本更新日志见仓库 `CHANGELOG.md`；问题与建议请到 [Issues](https://github.com/fadersketch/Promaid-mod/issues)。
