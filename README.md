# Promaid(更智能的车万女仆)

为《车万女仆》(Touhou Little Maid,TLM)制作的 Forge 扩展模组,让女仆真正"活"起来:自主建造、LLM AI 对话、长期记忆、战斗自保、自动装备武器与工具……**全部功能零依赖,只要求原版 TLM**。

- **Minecraft**:1.20.1
- **加载器**:Forge 47.4.21(1.20.1-47.4.21)
- **前置**:Touhou Little Maid ≥ 1.5.0(开发与测试基于 TLM 1.5.3)
- **许可证**:MIT
- **仓库**:github.com/fadersketch/Promaid-mod
- **版本**:v1.0.0(对应内部开发版本 1.5.252g15)

> 开发过程中使用了 AI 辅助编程工具;作者并非专业程序员,代码中可能存在缺陷,遇到问题欢迎反馈。

## 功能特性

### 🏗️ 建造系统
- **Promaid 手册(蓝图书)**:书 + 纸即可合成,内置 40+ 大型蓝图(别墅、宫殿、城堡、雕像、飞船……),女仆自动施工;
- **工头模式**:一条命令指挥多名女仆分工合作,全局建造进度一目了然;
- **区块冻结**:大型建造期间冻结相关区块,防止放置方块过多导致崩溃;
- 建造日志、材料统计、蓝图列表 / 设计工具(框选区域生成蓝图)。

### 🧠 LLM AI 女仆
- 接入任意 **OpenAI 兼容 API**(在游戏内配置面板填写),女仆获得 20+ 工具:挖矿、整理、烹饪、酿造、建造、给物品、移动、拾取、查询记忆、感知环境……;
- **主动对话**:女仆会主动汇报工作、提醒危险、表达情绪,而不是被动等指令;
- **长期记忆**:重要事件、故事、工作笔记跨存档会话保留,女仆"记得你";
- 情绪感知、回复反馈跟踪、配额管理(API 用量可限制)。

### ⚔️ 战斗与自保
- **自保行为**:低血自动回血、搭方块避险、传送回主人身边、水桶垫水、岩浆逃生、窒息 / 溺水提示;
- **自动装备**:按任务自动切换最佳武器 / 矿镐 / 工具,自动装备副手盾牌,主手武器快坏时提前更换(无备用才用到坏);
- **武器判定基于攻击力属性**,无任何武器黑名单——**Better Combat 等模组武器天然支持**,与原版武器同规则参与评分与切换;
- **主人死亡传送**:主人死亡时女仆自动传送到主人身边守护;
- 玩家伤害模式可配置(原版压制 / 完全免疫 / 无限制 / 百分比上限 / 仅一点伤害)。

### 🛠️ 任务与杂项
- 自动挖矿(支持连锁采集)、整理箱子、烹饪、酿造、钓鱼自动坐椅、农场操作、喂食与投喂药水(情境药水:溺水喝水肺、中毒喝蜂蜜……);
- 女仆伤害 / 拾取优先级、击杀播报、TTS 语音朗读、聊天气泡上限等细节优化;
- 全部功能可在游戏内配置面板逐项开关。

### 📖 内置手册
- 游戏内 Promaid 手册内置 **20 章详细介绍**:全部功能、详细使用教程、专业术语解释、运作逻辑、以及 **242 个版本的更新日志**。

## 安装

1. 安装 Minecraft 1.20.1 + Forge 47.4.21,以及 Touhou Little Maid 1.5.3;
2. 下载 `promaid-1.0.0.jar` 放入 `mods` 文件夹;
3. (可选)如需 AI 对话功能:游戏内打开 TLM 面板 → 模组详细配置 → 填写 API 地址与密钥。

旧版 maid_smart 存档数据(物品、任务、蓝图、记忆)完全兼容。

## 从源码构建

仓库自带一键构建链(仅 Windows,需要 JDK 17+):

```
gen_compile.py        # 扫描 promaid_src 自动生成编译参数(需先准备 compile_addon.txt 类路径)
compile_promaid.bat   # javac 编译,输出 out_promaid
build_promaid.py      # 组装 jar(classes + 资源 + META-INF + LICENSE)→ patched/promaid-1.0.0.jar
```

编译需要完整的 Forge 1.20.1 开发类路径(可直接使用 `.minecraft/libraries` 下的库 + 原版 TLM jar + MixinExtras),按 `compile_addon.txt` 的格式写入本地路径后运行。`promaid_src` 内全部为 SRG 名映射源码,与 TLM 1.5.3 官方映射一致。
