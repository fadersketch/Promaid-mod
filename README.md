# Promaid（更智能的车万女仆）

为《车万女仆》(Touhou Little Maid，简称 TLM) 制作的扩展模组。在 TLM 原有的女仆实体与任务框架之上，它扩展出**空袭飞行、扫帚空战、载具驾驶、蓝图建造、采集生产、日程排班、战术自保与 AI 记忆对话**等系统，让女仆在战斗、生产与日常行为上具备更高的自主性——会飞、会建造、会干活、会记事儿、会说话，还会在危险时保你的命。

- **1.20.1 版**：Minecraft 1.20.1 · Forge 47.4.x · 版本 **v1.3.3**
- **1.21.1 版**：Minecraft 1.21.1 · NeoForge 21.1.250 · 版本 **v1.3.3**
- **前置模组**：仅原版《车万女仆》TLM ≥ 1.5.0（实测 1.5.3）· **许可证**：MIT
- **仓库**：github.com/fadersketch/Promaid-mod

本模组分两层：**无需 AI 即可使用的核心系统**（战斗与飞行、生产与建造、自保与调度），以及**可选的 AI 功能**（记忆、对话、工具、语音，需自备一个 OpenAI 兼容站点）。

**只有一项硬前置，即原版车万女仆，不对任何其它模组做编译期依赖。** 武器判定基于原版攻击力属性，因此 TaCZ / 卓越前线 / 拔刀剑 / 史诗战斗 / 万法皆通等模组的武器**天然可用**，无需专门适配。所有功能均可在游戏内配置面板中逐项开关，并配有一本 **37 章**的内置手册说明用法。

> 开发过程中使用了 AI 辅助编程工具；作者并非专业程序员，代码中可能存在缺陷。平时以单人游玩为主，未针对多人服务器做优化，有此类问题请多加谅解，也欢迎到 [Issues](https://github.com/fadersketch/Promaid-mod/issues) 反馈。

**进游戏就会收到一本《Promaid 手册》**（遗失时用 `/give @p maid_smart:blueprint_book` 找回，或在工作台以「书 + 纸」合成），内含 37 章保姆式教学，每章先讲「是什么」再手把手教「怎么用」，关键步骤附有举例。配置面板为**两级菜单（7 大类 / 31 小类）**，手册正文里的「配置入口」链接可一键跳到对应参数行，改完点「保存并返回」立即生效。

> 本页是功能总览；本版更新内容见仓库根 `RELEASE_NOTES_v1.3.2.md`（GitHub Releases 同款）。

## 战斗

### 空袭 —— 会飞的女仆

给女仆穿上**鞘翅**、带上**武器**和**可以飞行的道具**（**烟花火箭 / 孔雀羽扇 / 能上天的位移类法术**任一），把任务切换为空袭，她自己飞起来打怪，不再贴地追着砍。**装备不齐她不会飞**，切到任务当场就报缺哪一件。

| 模式 | 怎么打 | 武器位 |
|---|---|---|
| **近战空袭** | 爬到敌人上方 → 收翅俯冲 → 触底前一记近战 → 再起飞，循环 | 任意近战武器（剑 / 斧 / 三叉戟 / 重锤 / 模组近战） |
| **远程空袭** | 在天上盘旋，用手里的远程武器持续开火 | 任意远程武器（弓 / 弩 / 御币 / 三叉戟 / 模组弹射 / 枪械） |

- **三件套**：鞘翅（切任务后她自己穿到胸甲槽）+ 武器 + 可飞行道具（放背包即可）；远程空袭额外需要匹配弹药，御币与三叉戟不消耗。空袭**不响应自主切换**——不会被「主动参战」改任务，也不会自己换掉你给的武器。
- **收翅俯冲那一击**：1.21.1 手持**重锤**时按玩家同款的重锤下落加成结算（含风爆的原地爆炸与自我顶起），落差按**本轮最高点**计算——**飞得越高这一锤越狠，不设上限**；其它武器按原版**暴击 ×1.5** 加附魔。命中率有三道保险（判定距离 4 格 / 收翅 2 tick 即可出手 / 对身边 2.5 格内的其它合法敌对目标补一记），女仆一律跳过、**绝不误伤主人与宠物**，且需要视线通过。
- **索敌**以女仆为圆心、**半径 50 格**，锁定后持续瞄准；视线只作为**新锁定**的门槛，「隔墙不出手」依然成立。
- **空袭牵引绳**：以她自己为圆心 **100 格**（可调，0 = 关闭）内找不到主人，就**立刻把她传送回你身边**——强制生效、无视地块、可以空中传送，避免她飞太高把目标打死后自己回不来。
- **空袭期间**不接受其它传送（跟随拉回 / 跨维跟随 / 自保归位一律让位）；玩家手动「一键集合」与主人死亡传送照常生效。她不触发自保，但**不免疫真实伤害**，照样会被打下来；滑翔 / 悬空 / 俯冲时不搭方块，落地自己放水 / 细雪接住。**默认开着「空袭免疫摔落伤害」**，想按原版吃摔伤可在面板关掉。
- **空袭轰炸**：打完那一记、远程开火之后，她顺手按背包里的材料投放炸弹——**末地水晶**（黑曜石底座 + 水晶，威力最猛）、**重生锚**（需 1 颗萤石充能，下界不生效）、**床**（只在原版真会爆炸的维度放）、**投掷 TNT**（需要 TNT + 点火料，打火石优先；**TNT 矿车也算**，扔出去的就是那一辆点着的矿车）。材料齐的几段**一拍只放一段**（末地水晶 / 重生锚 / 床 / TNT 按约 2~3 秒错开依次投放，上一发落停再放下一段），各占各的落点。「轰炸破坏方块」与「轰炸伤到主人 / 友军」默认都**关**（只炸伤害与击退、地形一点不动，主人与同主女仆不掉血也不被震），**她自己也不会被自己的炸弹炸到或推飞**；爆炸火焰改成**粉色火焰**（不蔓延、自己灭、不点燃任何人）。
- **空袭的 34 项数值全部可调**（起飞段时长与仰角、盘旋半径与期望高度、补推窗口、开火间隔与射程……），默认值与硬编码一字未改。

### 扫帚模式 —— 骑着扫帚飞着打

给她一把**扫帚** + 任意**远程武器**，把任务切成**扫帚模式**，她自己骑上扫帚、用主手武器在空中打。**只有你手动指定才会进**——被怪袭击时她不会自己换扫帚。齐备三件：扫帚（背包里或世界里放着的都行）+ 远程武器 + 弹药（弓弩要箭；枪械要**对得上那把枪**的子弹，御币 / 三叉戟 / 能量枪不消耗）；缺件会报在气泡里并**原地待命**。

- **接敌**：先爬到敌人上方 **12 格**（可调 2~32）再**绕圈开火**，开火链路与远程空袭完全同款。
- **绕圈不是死圈**：半径随机缓动、旋向按 UUID 对半、转速缓慢游走，并保证离敌最近距离（默认 6 格）与接敌时的同伴间距（4 格）——几只女仆不会落在同一条射线上互相串击。
- **没敌人时**：守家时沿工作范围巡逻（默认离地 8 格、不追圈外）；否则贴着你飞（起手 / 收手 6 / 3 格）；**没事干会落回地面待命**，不会一直挂在半空。
- **锁敌**与空袭共用同一个索敌器（50 格发现、锁定后维持到 128 格、锁定期间不要求视线）。
- **牵引绳**：离参照点超 100 格连人带扫帚拉回（可调，0 = 关）；守家时参照点是工作区圈心，你走多远都不拽她。
- **空中避障**：卡墙脱困按她自己的身体判格（不钻一格死洞）、真被闷住立刻脱离、泡进岩浆或被点着立刻传送出去、多只女仆不叠罗汉不贴地。
- **限制**：她是骑乘状态，所以**只能用主手武器打**——不施法，也不放 TNT / 末地水晶 / 重生锚 / 床。

### 三叉戟：近战 / 远程 / 激流旋转冲击

三叉戟在本模组里有三条明确分工，近战与空袭两条线都能用：

- **当近战武器**：攻击模式与近战空袭都认它（原版近战伤害与附魔照常结算）。
- **当远程武器**：远程空袭里能投掷，而且**不消耗弹药**。注意**附了激流就投不出去**——那是原版「水里突进」的设定。
- **激流旋转冲击**（默认开，可关）：主手拿着**带激流附魔的三叉戟**时，普通挥砍被**替换成旋转冲击**——近身 4 格内触发（地面要站在地上），空袭的**收翅俯冲那一记在空中也替换**（空中旋转期间不会自我摔伤）；旋转 16 tick，撞到谁就结算一次伤害，**同一目标每次突进只打一下**。

### 载具驾驶（卓越前线）

女仆能开车、也能从车上打。她坐**驾驶位**就能开（引擎认「第一乘客」，不要求是玩家）；把目标**同时写进炮塔与武器位的 AI 目标**，用载具自己的炮弹打；她背包里对得上的子弹会**自动搬进载具的弹药容器**，当前弹种没弹时会自动换弹种 / 换炮。地面载具接敌会**绕圈**（半径按车速与车体自适应，撞墙自动调头）并有**真刹车**，不再一路漂移，也**不撞主人**。

四种飞行载具各接各的路：**直升机**航向 / 俯仰走鼠标通道、高度走总距，跟随时比主人高三格悬停、接敌时升到敌人上方绕圈；**固定翼**没有竖直轴、不能悬停，改用引擎自带的盘旋；**飞艇**并入直升机的空战电路；**汤姆 6** 的油门与姿态改由本模组直接驱动，她会飞、会跟着你走。飞行载具**投弹前会先爬升**到「目标高度 + 指定格数」（默认 20 格）并**没爬到位就不投**，避免把自己圈进爆心。

**降落方式可切换**（「物品 → 骑乘指挥棒」页）：「**拟真降落**」默认关 = 上一个版本的降落方式，开了 = 以你脚下为圆心规划跑道、对准进近、沿下滑道压高度；「**滑翔类盘旋加高（格）**」默认 60，老存档里仍是旧默认值 30 的会自动迁移。

> 少数**操作门槛过高、或座舱代码只认玩家**的载具被刻意排除，拿指挥棒右击它们时她会回一句提示；完整名单见「已知情况」。

### 骑乘指挥棒

（拴绳 + 木棍）让女仆骑坐骑 / 载具 / 龙，跟着你走。

- **顺序固定：先右击坐骑，再右击女仆**（反过来会被回一句提示）。
- 手持指挥棒的三种操作：**右击** = 选中 / 配对 / 解除；**左击** = 主驾 ↔ 副驾换座（多座载具专用）；**空手右击**她开的载具 = 坐进空着的副驾。手里拿着指挥棒时**绝对不会登乘**。
- 坐骑判据是原版「能不能上鞍」这个接口，不写死实体 id，别的模组坐骑零适配；她的近战 / 远程走位原样还原（走位意图不变，只是把「她走」换成「坐骑走」）。**一只坐骑同时只服务一位女仆**；一位主人可同时带多条链路。

### 武装拴绳（二号位）

（拴绳 + 铁锭 ×2）把她当一号位（她飞、她开火），你当二号位（挂在她身下开火）。

- **两档绑定**：**扫帚模式**下她已经在扫帚上时右击她，你从扫帚上下来挂到二号位；**空袭模式**下随时能绑，她还没起飞时先进入**牵绳档**（你自由活动、她跟着你走），等她真起飞才把你挂上去，落地满 2 秒再放下。
- **绑定态右击她** = 解除并坐回驾驶位；**在驾驶位上右击她** = 换到二号位——来回切就是「我开 / 她开」两种坐法（全程她没下过鞍）。
- **一眼看得见**：第一人称下她与那把扫帚**半透明**（只对你 + 第一人称，默认 0.1 可调）；被绳子选中还没起飞的她带**金色描边**；屏幕左上角多一行蓝色「◆ 绑定中」。
- **绳子不会自己断**：落地不会自动放人，只有落水超过 0.6 秒才放下你；解除瞬间给 5 秒摔伤豁免，挂着时你和她**同款免伤**（卡墙 / 挤墙 / 摔落 / 撞墙）。
- **拴绳操控**（默认开，仅空袭档）：她**没有目标**时，只要你手里拿着武装拴绳，**你的视线就是她的机头**——平视不掉高、抬头爬升、低头下降。

### 巡逻航图

（纸 + 指南针 + 墨囊）给「扫帚模式 + 在家模式」的女仆**画一条闭环轨道**，让她沿你画的线一圈圈飞，替代原本「绕工作范围盘旋」的守家行为。手持航图右键开界面 → 创建轨道 → 绑定女仆并「开始标记」→ 退出后**按鼠标中键**记点（落点即你此刻的位置）→ 回界面「连接」成闭环。**一本航图能装 16 条轨道**，各有名字 / 净空半径 / 标记点 / 是否闭环；标记只在你**手持航图**时可见。「连接」没有门禁——点数不够、坡度太陡、自交都会照连不误，能不能飞由她自己兜底。

## 生产与工作

- **排班表**（纸 + 墨囊）：手持右键打开全部女仆列表（跨维度也在列），点一只进去给她排一整天——早班 / 晚班 / 全天，工作时间平均分成 6 个任务时段、当前时段整行高亮、一键集合、自动在家模式、大范围活动与空闲散步。
- **建造**：按蓝图**一块一块真实搭出来**，材料真实消耗、缺料会暂停并告诉你补什么。蓝图来源四种——随包附赠的 **79 套已授权蓝图**（首次运行自动解压）、LLM 对话现场生成、外部图纸文件（`.nbt / .snbt / .litematic / .schem / .json`）、AI 设计器。工地有金色框预览 + 青色幽灵投影（**Z 键旋转 90°**）、工头模式、进度持久化、缺料自动替代。
- **指标石**（9 块平滑石 3×3）：手持它，视线指到的方块显示**绿框** → 右键锁定成**红框** → 再右击你的女仆绑定 → 从她脚下到锁定点之间所有空气方块变成**橙色幽灵方块**，她立刻一格一格填过去。材料先从她背包拿、不够从你的背包拉；创造模式视为无限。
- **挖矿 / 伐木**：矿表白名单（默认名单尾带 `#forge:ores` / `#c:ores` 标签行）+ **就近选矿**、连锁采集、**智能挖矿 / 智能伐木**、搭方块防掉落 + 自动回收；伐木默认带 `#minecraft:logs` 标签行、随手补种、骨粉催熟。
- **烧制 / 酿造 / 农场 / 宰杀**：什么能烧就烧、多女仆各占一个炉子；酿造有批量与定向两种模式；农场连锁收获 / 批量种植 / 耕地标记制；宰杀按种类计数阈值自动宰杀，不误杀驯服宠物。
- **投喂**：判定是「有食物属性 + 不在黑名单」，与 TLM 自己「女仆饿了吃」完全同口径；支持模组食物，默认不喂腐肉、生肉、金苹果那几类。
- **压缩盒**（4 樱花木板放四角 + 4 钻石放四边中点 + 1 粉色染料放正中）：**只有 5 格，但每格能堆 114514 个**，放进女仆背包就等于是**她背包的延伸**——她真的会从盒子里拿材料、也会吃盒子里的食物。压缩盒本身与带附魔的物品一律不能放入。

## 自保与辅助

- **自保**：生命值低于 30% 且处于真实威胁时启动，回血阶梯 / 垫高 / 逃跑；环境小伤轻处理，着火时直接传送进水灭火。
- **死亡与复活**：致死自动收回魂符（有冷却）；若未能救下，墓碑到期后女仆在主人的重生点复活（重生点不可用则直接在主人所在位置复活），背包、饰品、任务与模型按死亡瞬间还原。
- **主人免伤（三层防护）**：伤害事件总闸 + 全部攻击注入点过滤 + 定期清仇恨——雪地打雪仗只会扔雪球，绝不挥刀；同主女仆之间也互不误伤。
- **单兵战术 / 贴身辅助 / 武器自动切换**：PVP 式走位、跳劈暴击、放风筝、举盾格挡；自动投喂与治疗；武器按 **DPS（最终伤害 × 攻速）+ 附魔 + 耐久**评分自动换——**判定全基于原版属性，没有武器黑名单**。
- **贴身辅助**：主人 16 格内，女仆会自动投喂、治疗、解除负面效果、投抗火与水肺药水、共享盾牌与不死图腾；安装《口渴》后还会喂水。女仆之间也会互相支援。
- **被动技能**：落地水 / 落地雪、岩浆逃生放水、主人死亡传送、搭路、飞行跟随（默认关）。
- **床铺互通**：女仆能睡原版 16 色床，**玩家也能睡女仆床并把它设为重生点**。
- **安全与区块保载**：有主女仆所在区块持续保持加载；寻路主动绕开岩浆 / 火 / 仙人掌等危险方块；被困基岩顶层或掉出世界底部自动救援传回；**不得把方块搭在主人身上**（防把主人挤住或盖住头，正常垫脚搭路不受影响）。

## AI 系统（可选，自备站点）

本组功能全部可以关闭，且仅需玩家自行配置一个 OpenAI 兼容站点。

- **AI 记忆**：重要事实、关系三元组、主人画像、工作笔记，外加日 / 3 日 / 周 / 月四级记忆日记，睡一觉自动整理并沉淀长期记忆。
- **主动对话 / 工作播报 / 自主决策**：她会自己开口（气泡 + 语音），关心你重伤、夜晚困倦、好感升级，也会在空闲时自己判断该去干什么。所有主动发言共用日配额（默认 40 次 / 天）控成本。
- **17 个 AI 工具**：直接对她说「过来我身边 / 给我钻石 / 去打那只怪 / 记住我喜欢喝红茶 / 造一个 5×5 现代小屋」。
- **感知与情绪**：纯规则的感知系统（敌人出现 / 离开、主人受伤 / 低血、天气变化）配合 PAD 三维情绪模型。
- **语音**：内置**日语语音包（开箱即用、不联网）**，也可接自己的 TTS。

> **需要联网的地方只有一处**：AI 对话 / 记忆 / 工具 / 蓝图生成需要你自己填一个 OpenAI 兼容 API 站点（模型、地址、密钥都在游戏内配置面板填写）。不填 = 这些功能自动不工作，模组其余全部功能照常，**不会偷偷发任何请求**。

## 安装

1. 安装对应版本的 Minecraft 与加载器：**1.20.1 + Forge 47.4.x**，或 **1.21.1 + NeoForge 21.1.250**；
2. 安装前置《车万女仆》TLM（1.20.1 用 Forge 版，1.21.1 用 NeoForge 版）；
3. 把 `promaid-*.jar` 放入 `mods` 文件夹（**必须在游戏完全退出后替换**——运行中换 jar 会让 ModLauncher 按旧偏移读到坏数据，表现为加载阶段莫名崩掉）；
4. 进游戏拿手册；想用 AI 功能，先按手册里的配置章节把 OpenAI 兼容 API 站点配好。

安装新版本前请**删掉 `mods` 里的旧版本 jar**（modId 相同，同时加载会启动失败）。旧存档可无缝升级：物品、任务、蓝图、记忆与排班等持久化数据沿用 `maid_smart` 命名空间。
