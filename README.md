# Promaid-mod
为《车万女仆》(Touhou Little Maid,TLM)制作的 Forge 扩展模组,让女仆真正"活"起来:自主建造、LLM AI 对话、长期记忆、战斗自保、自动装备武器与工具……**全部功能零依赖,只要求原版 TLM**。   - **Minecraft**:1.20.1 - **加载器**:Forge 47.4.21(1.20.1-47.4.21) - **前置**:Touhou Little Maid ≥ 1.5.0(开发与测试基于 TLM 1.5.3) - **许可证**:MIT - **版本**:v1.0.0(对应内部开发版本 1.5.252g15)
