# Promaid（更智能的车万女仆）

为《车万女仆》(Touhou Little Maid, TLM) 制作的扩展模组，让女仆真正"活"起来——会建造、会干活、会记事儿、会说话，还会在危险时保你的命。

- **1.20.1 版**：Minecraft 1.20.1 · Forge 47.4.x · 前置 TLM ≥ 1.5.0（实测 1.5.3）· 版本 **v1.1.0**
- **1.21.1 版**：Minecraft 1.21.1 · NeoForge 21.1.250 · 前置 TLM ≥ 1.5.0（实测 1.5.3-neoforge）· 版本 **v1.1.0-beta.2**（beta）
- **许可证**：MIT · **仓库**：github.com/fadersketch/Promaid-mod

**纯独立前置**：只要求原版车万女仆（TLM），不对任何其他模组做专属联动（曾经的第三方软联动已全部移除）。不过**武器判定基于原版攻击力属性**，所以 tacz / 卓越前线 / 拔刀剑 / 史诗战斗 / 万法皆通等模组的武器**天然可用**，无需专门适配。

> 开发过程中使用了 AI 辅助编程工具；作者并非专业程序员，代码中可能存在缺陷。开发者平时只玩单人模式，未针对多人服务器做优化，有此类问题请多加谅解，也欢迎到 Issues 反馈。

## 一句话看懂

Promaid 按「**要不要 AI**」分两大类功能：

- **不需要 LLM，配好就能用**：建造执行、挖矿、伐木、烧制、酿造、农场、宰杀、战斗自保、单兵战术、武器/工具自动切换、被动保命技能、贴身辅助、感知播报、情绪、TTS 语音包、排班调度、女仆管理；
- **需要先配 LLM 站点**：主动对话、工作播报、自主决策、AI 记忆、AI 工具（对话直接下命令）、LLM 现场生成蓝图、AI 设计器。

**进游戏就会收到一本《Promaid 手册》**（丢了用 `/give @p maid_smart:blueprint_book`，或工作台「书 + 纸」合成），里面有 26 章保姆式教学，每章先讲「是什么」再手把手教「怎么用」，关键步骤都配了【举例】。

## 核心功能

### 📅 排班表 —— 全女仆日程调度（v1.1.0）

新物品**排班表**（纸 + 墨囊合成，开局也会和手册一起自动送进背包一次）：手持右键打开全部女仆列表（跨维度也在列），点一只进去给她排一整天。

- **列表页**：搜索框按名字过滤、每行显示血量与所在维度、全员一键切早班/晚班/全天、批量应用任务、**⚑ 一键集合**（含其他维度的女仆，按最后出现位置自动强载区块送来）；
- **快捷设置页**：直接遥控她「现在」干什么——工作模式与任务都有 ◀ ▶ 左右箭头快速切换；
- **排班页**：选班次（早班/晚班/全天），把工作时间平均分成 6 个任务时段（全天每份 4 小时、早晚班 2 小时），点任务名**整页跳转任务选择器**，任务可重复；**当前时段整行绿色高亮**，一眼看到她现在在干什么；保存后每到时段边界自动切换（按游戏内时间，一天 = 现实 20 分钟）；
- **让位规则**：自保保命 > 排班表 > 主动战斗还原 > 你手动切的任务；
- **排班锁定**：排班开着的女仆，任务/工作模式按钮锁定，在原版界面硬改会被当场弹回；
- **自动在家模式**：排班期间自动守家按日程干活，不跟主人乱跑、不被集合/死亡传送带走；关闭排班即解除；
- **大范围活动与空闲散步**：活动半径最低 32 格（原版只有 8~16），空闲时自己散步不站桩发呆。

### 🏗️ 建造系统 —— 照着蓝图真实搭建

女仆能按蓝图把建筑**一块一块真实搭出来**，材料从背包真实消耗，缺料会暂停并告诉你补什么。

- **四种蓝图来源**：① 随模组附赠 **81 套已授权蓝图**（房屋/地形/天空/树木/武器/水/红石/节日/装饰/载具/雕像，从中世纪庄园、上海中心大厦到天空之城、巨型载具都有，首次运行自动解压开箱即用）；② LLM 对话现场生成（「造一个 5x5 现代小屋」）；③ 外部图纸文件（`.nbt/.snbt/.litematic/.schem/.json`，放进 `config/maid_smart/blueprints/` 即用）；④ AI 设计器（「设计一个中式庭院」）；
- **工地预览**：金色框预览占地 + 青色幽灵方块投影，**Z 键整体旋转 90°**；确认后变红色区块框钉在工地，走出区块也能看清轮廓；
- **工头模式**：一个区块一只工头，缺料/跳过/完成统一汇报；多只女仆可绑同一区块一起建；
- **进度持久化**：材料表、进度条（百分比 + 速度 + 预计完成时间）随女仆存档，重启继续；
- **缺料自动替代**：同族材料（任意木板顶橡木板）→ 自定义替代方块；机械蓝图按「结构→惰性机构→活动件→传感件→动力源」六层自下而上，动力源最后落地避免半途通电误触；
- 还有极速模式、放置配额、区块冻结防崩溃等细节。

### ⛏️ 挖矿 / 伐木 —— 自动找矿找树

**挖矿**：切「挖矿」任务，她扫描找矿 → 走性价比最高的矿 → 持镐开采。只挖**矿表白名单**里的矿石（价值分可调，钻石 500 / 铁金 250 / 煤 100…），综合价值、距离、深度惩罚、穿透预算评分选矿。

- 连锁采集（矿脉一次挖完）、自动收集（掉落直接进背包）、透视感知（默认关，开启后可隔墙挖穿取矿）、搭方块防掉落 + 自动回收、软方块不耗耐久、废石保留量防背包塞满；
- **发呆看门狗**（默认 8 秒）：原地卡死自动重置挖矿状态重新找矿，不用收魂符重放救她；
- 经验球归属：8 格内有玩家玩家优先，否则最近挖矿女仆吸收。

**伐木**：切「伐木」任务，找树 → 持斧砍 → 连锁砍完整棵树（树叶不挡视线）。

- **模组原木默认自动识别**（带原版 `#logs` 标签的都认），也可精确配置木材表；
- 连锁砍伐、自动收集、透视感知（默认开）、废石保留、发呆看门狗；
- **随手种树**：自动捡起地上树苗并补种，森林越砍越有；种点会筛选「真正长得成」的格子（3×3 无碰撞方块、正上方 7 格净空、光照达标）；深色橡树苗不种不捡（单株不生长）；
- **骨粉催熟**：背包有骨粉时自动催熟身边树苗（每 0.5 秒一株，不受光照限制）。

### 🔥 烧制与酿造

- **烧制**：切「烧制」任务，在附近找熔炉/高炉/烟熏炉，把背包里的生食烤熟、矿石烧成锭。v1.1.0 起**什么能烧就烧什么**（当前世界熔炉配方里非装备类都能喂，含模组食材/粗矿）；**多只女仆各占一个炉子**，不抢炉不顶号、消息不刷屏；
- **酿造**：切「酿造」任务，找酿造台按配方下料。**批量模式**（有什么正向材料就酿什么）或**定向模式**（只按目标药水的配方链精确下料，缺料停止等待、补料自动继续）——用**女仆药剂手册**（水瓶 + 书本合成）右击女仆配置；**成品药水当基底下料**（如 3 分钟夜视 + 红石自动延长成 8 分钟）。

### 🌾 农场与杂项

- **农场连锁收获 / 批量种植**（收割蔓延整片田、空耕地一次全种上，种子真实消耗）；
- **耕地标记制**（v1.1.0）：只锄「曾经是耕地」的地块——超平坦地形不再连锁扩散成一片耕地；自然生成的耕地自动补标，草径也认；
- **锄地索敌**：主动走向 16 格内可锄地块；**作物骨粉催熟**：自动给未成熟作物施肥；
- **宰杀任务**（v1.1.0，新工作模式）：检测周围牲畜按种类计数，某一种超过阈值时每 3 秒随机宰杀一只（正常掉落 + 挥臂动画），没活时四处闲逛；驯服宠物与亡灵马不会误杀。

### ⚔️ 战斗与自保

- **被动保命系统**（默认开，优先级压过一切状态）：血量低于触发线（默认 30%）进入保命——回血、垫高躲怪、逃跑，环境危险（岩浆/溺水/窒息）自救，威胁消失且血回安全线才解除；
- **回血阶梯**：增益药水 → 治疗药水 → 金苹果 → 治疗食物；
- **逃生手段**：末影珍珠脱身、传送回家（主人旁有安全落点才传，传送有冷却）、窒息上浮、着火时自动灭火（附近有水源直接传进水）；
- **保命道具优先**（v1.1.0）：带着绀珠之药/不死图腾时低血**不逃跑**，死不了就留下来继续打；
- **致死自动回魂符**（v1.1.0，全新）：受到**会致命的那一击**且身上没有保命物品时，当场自动收回魂符——不用再跑去神龛复活，你从魂符重新放出即可；重新释放后有冷却（默认 60 秒，从释放时刻起算）；
- **环境伤害软处理**（v1.1.0 新口径）：踩仙人掌/轻微摔伤等小伤害不再触发整套逃跑，脱离危险源后原地休整回血；真正的持续威胁仍按完整自保处理；
- **主动切换战斗**（v1.1.0，默认开）：你被有来源的攻击打（怪物/玩家/弹射物）或攻击敌对生物时，附近 16 格内女仆无论干什么都立即切战斗来保护你，威胁消失约 10 秒后自动还原原任务；选战斗模式时扫描背包所有攻击类任务，**背包里有模组武器必定切它专属的战斗模式**（拔刀剑→拔刀剑模式、史诗战斗→战斗模式），敌人远选远程、近身选近战，战中还会动态换战术。

### 🛡️ 主人免伤（三层防护）

女仆**绝不伤害主人与同主女仆**——这是针对实测 bug（带女仆到雪地打雪仗后，她会对主人跳劈）的专门加固：

1. **伤害事件总闸**：女仆造成的主人/友方伤害在攻击/受伤/结算三处直接取消；
2. **全部攻击注入点过滤**：战术跳劈、近战横扫、中立威胁反击、自保反击（含弹幕/射箭）、LLM 攻击工具，目标为主人/友方时一律不执行；
3. **定期清除仇恨**：每 2 秒把主人/友方从 `ATTACK_TARGET`、实体目标、复仇目标里清掉。

结果：雪地打雪仗只会扔雪球，**绝不会对主人挥刀**；同主人的女仆之间也互不误伤。

### 🎯 单兵战术 / 贴身辅助 / 武器切换

- **单兵战术**（PVP 式走位，默认开）：近战贴脸绕圈侧移 + 打一刀退一步 + 跳劈（剑单敌 100% 空中暴击）；远程保持理想射程放风筝 + 横移绕圈；攻击冷却间隙举盾格挡、冷却满放盾攻击；装上 TACZ/卓越前线时枪械任务全套战术照常生效；
- **贴身辅助**：你饱食度低时自动投喂（有音效 + 系统消息）、自动治疗、战斗任务下自动配盾；
- **武器与工具自动切换**：干活/战斗前自动换最合适的工具——近战武器按 **DPS（最终伤害 × 攻速）> 附魔词条 > 剩余耐久**评分；挖矿发现目标矿才换合适的镐；伐木自动换斧；剪刀任务自动拿剪刀（认 `forge:shears` 标签的模组剪刀）；盾牌爆了自动补；只剩 ≤10% 耐久才拉黑，主手快坏会提前换下一把。**判定全部基于原版属性系统，没有任何武器黑名单**——其他模组的武器只要带攻击力属性就正常使用。

### 🪂 被动技能（独立板块）

不用切任何任务，任何状态下都生效：

- **落地水**（默认开）：背包有水桶时坠落超过阈值自动放水缓冲，水桶不消耗、落地后收回；**落地雪**（v1.1.0）：有细雪桶时在落点铺 1×1 雪垫接住自己（下界也能用，水会蒸发、细雪不会）；
- **岩浆逃生放水**：垫高自救后周围没水源且包里有水桶，就地放水灭火（1 秒后收回）；
- **主人死亡传送**：主人死亡时无视距离强制传送到重生点（床/重生锚，跨维度通用）；home 看家/坐着/骑乘中的女仆保持原位；
- **搭路**（v1.1.0，默认关）：背包有可放置方块且周围无敌对生物时，只要与你隔沟/隔空就朝你方向铺方块并踩上去一路接近（平地跟踪距离无上限，像僵尸搭桥追人）；你远高于她时垫方块搭高靠近；垫的方块会自动回收，不破坏地形；挂着战斗任务但没在真打时也照常搭路，**一旦接战立即停搭转入战斗**。

### 🧠 AI 记忆系统

女仆会把重要的事**记下来**，下次对话还记得——这是她「有人味」的核心（需 LLM）。

- **记什么**：重要事实段落、关系三元组（主人-喜欢-红茶）、主人画像、工作笔记；
- **怎么记**：对话积累到阈值（默认 10 条）LLM 自动提取、她主动调用 `remember` 工具、感知/情绪系统写入；
- **记忆日记**（多级索引）：把每天的事写成第一人称日记——日/3日/周/月四级，跨度越大压缩越狠；可用 `query_memory_index` 翻旧日记回答「上个月我们做了什么」；
- **睡一觉自动整理**：全员真实睡过夜后生成当日日记，并把够重要的记忆**沉淀为长期**（不再随时间淡忘）；服务器上玩家登出也算一天结束；
- **人格种子**：每只女仆独立的人设文件，与聊天记忆分离，聊天不改写人格；**情绪快照**：每条新记忆附带当时的 PAD 情绪；
- **链路调试**：手册「女仆记忆」页可对单条记忆上调/下调重要度、标记删除、恢复、强化；
- **遗忘**：记忆按衰减周期（默认 7 天）慢慢淡出，重要度高的保留。

### 💬 主动对话 / 工作播报 / 自主决策

女仆会**自己开口说话**（气泡 + TTS），不用你先搭话（需 LLM）：

- **主动对话**：关心你重伤、夜晚困倦、好感升级、长时间沉默找话题；日上限与冷却可调；击杀邀功默认关（想听可在面板打开）；
- **工作播报**：干活卡住时用气泡解释原因（缺什么料/够不到/被挡路）；
- **自主决策**（必须 LLM）：空闲 + 白天 + 主人在 16 格内时，她**自己判断该干什么**并换任务（去种地/去挖矿），默认 10 分钟冷却、日上限 10 次；
- **回复反馈学习**：你说「别说了/好烦」她记住不再提该话题；说「谢谢」强化记忆；还会记录你多久没理她；
- **输出语言**：可强制中文或跟随游戏语言；所有主动发言共用 **API 日配额**（默认 40 次/天，0 = 不限）控 LLM 成本。

### 👁️ 感知与情绪

- **感知系统**（纯规则、零 token）：女仆会「注意到」敌人出现/靠近/离开、主人受伤/低血/盯着她看、天气变化并播报/记入记忆（同类事件有限频防刷屏）；
- **情绪系统**（PAD 三维模型）：愉悦-唤醒-支配独立于 TLM 好感等既有数值，由事件驱动（你喂她/夸她/打她都会改变），无事件时缓慢回归，情绪会注入对话上下文让她说话带着当下心情。

### 🔊 语音系统（TTS）

- **音量倍率**：TLM 原始语音偏小，默认放大到 2.0 倍（0.1~5.0 可调）；
- **系统消息朗读**：感知/工作/自保等规则气泡也能播语音（独立冷却防轰炸）；
- **系统语音包**：把常用系统消息预制成 ogg 音频放进 `config/maid_smart/system_voice/`（`manifest.json` 映射文本→音频），命中直接播放、免 TTS，一次制作永久使用；面板里有「选择文件导入」按钮直接选 zip；
- **语音缓存**：生成的音频缓存复用，上限可调，超出删最旧。

1. 安装对应版本的 Minecraft / 加载器（1.20.1 + Forge 47.4.x，或 1.21.1 + NeoForge 21.1.250）；
