# Promaid（更智能的车万女仆）

为《车万女仆》(Touhou Little Maid, TLM) 制作的扩展模组：让女仆会飞、会建造、会干活、会记事儿、会说话，还会在危险时保你的命。

- **1.20.1 版**：Minecraft 1.20.1 · Forge 47.4.x · 前置 TLM ≥ 1.5.0（实测 1.5.3）· 版本 **v1.3.0(beta)**
- **1.21.1 版**：Minecraft 1.21.1 · NeoForge 21.1.250 · 前置 TLM ≥ 1.5.0（实测 1.5.3-neoforge）· 版本 **v1.3.0(beta)**
- **许可证**：MIT · **仓库**：github.com/fadersketch/Promaid-mod

**纯独立前置**：只要求原版车万女仆（TLM），不对任何其他模组做专属联动。不过**武器判定基于原版攻击力属性**，所以 tacz / 卓越前线 / 拔刀剑 / 史诗战斗 / 万法皆通等模组的武器**天然可用**，无需专门适配。

> 开发过程中使用了 AI 辅助编程工具；作者并非专业程序员，代码中可能存在缺陷。开发者平时只玩单人模式，未针对多人服务器做优化，有此类问题请多加谅解，也欢迎到 Issues 反馈。

## 一句话看懂

Promaid 按「**要不要 AI**」分两大类功能：

- **不需要 LLM，配好就能用**：**空袭（会飞的女仆）**、**扫帚模式**、**武装拴绳（二号位）**、**骑乘指挥棒**、**卓越前线载具**、三叉戟激流旋转冲击、建造执行、挖矿、伐木、烧制、酿造、农场、宰杀、战斗自保、战斗模式分类表、单兵战术、武器/工具自动切换、被动保命技能、飞行跟随、贴身辅助、压缩盒、感知播报、情绪、TTS 与内置日语语音包、排班调度、指标石、女仆管理；
- **需要先配 LLM 站点**：主动对话、工作播报、自主决策、AI 记忆、AI 工具（对话直接下命令）、LLM 现场生成蓝图、AI 设计器。

**进游戏就会收到一本《Promaid 手册》**（丢了用 `/give @p maid_smart:blueprint_book`，或工作台「书 + 纸」合成），里面有 **35 章保姆式教学**，每章先讲「是什么」再手把手教「怎么用」，关键步骤都配了【举例】。

## ★ v1.3.0(beta) 新增

### 两个新道具

**武装拴绳**（Combat Leash，合成：拴绳 + 铁锭 ×2）——粉丝点单的「武装直升机」玩法：把她当一号位（她飞、她开火），你当二号位（挂在她身下开火）。

- **两档绑定**：**扫帚模式**下她已经在扫帚上时右击她 → 你从扫帚上下来挂到二号位；**空袭模式**下随时能绑，她还没起飞时先进入**牵绳档**（你自由活动、她跟着你走），等她真的起飞才把你挂上去，落地满 2 秒再把你放下；
- **绑定态右击她** = 解除并坐回扫帚驾驶位；**在扫帚驾驶位上右击她** = 换到二号位——两半互逆，来回切就是「我开 / 她开」两种坐法（换座走原版「玩家插队」规则，**她全程没下过鞍**）；
- **一眼看得见**：第一人称下她与那把扫帚**半透明**（只对你 + 第一人称，默认 0.1 可调，填 1.0 = 关掉）；被绳子选中还没起飞的她带**金色描边**；绳子是**原版拴绳同款**的白色丝带（隔远不消失、两端按帧插值）；屏幕左上角多一行蓝色「◆ 绑定中」；
- **绳子不会自己断**：落地不会自动放人，只有落水超过 0.6 秒才放下你；解除瞬间给 5 秒摔伤豁免，挂着时你和她**同款免伤**（卡墙/挤墙/摔落/撞墙）；
- **数值**：悬挂距离（默认 2.6 格，可调 0.5~6.0）、扫帚额外下沉（默认 0.3）、**拉扯**（默认开，绷紧时真的拉她，分档照搬原版拴绳）；
- **拴绳操控**（默认开，仅空袭档）：她**没有目标**时，只要你手里拿着武装拴绳，**你的视线就是她的机头**——平视不掉高、抬头爬升、低头下降；
- **二号位重锤猛击**（仅 1.21.1 树，只对空袭档生效）。

**骑乘指挥棒**（Ride Baton，合成：拴绳 + 木棍）——让女仆骑坐骑 / 载具 / 龙，跟着你走。

- **顺序固定：先右击坐骑，再右击女仆**（反过来会被回一句提示——「先选女仆」那条路实机不可靠，已刻意堵死）；
- **手持指挥棒的三种操作**：**右击** = 选中 / 配对 / 解除；**左击** = 主驾 ↔ 副驾换座（多座载具专用）；**空手右击**她开的载具 = 坐进空着的副驾。**手里拿着指挥棒时绝对不会登乘**；
- **原版坐骑**判据是「能不能上鞍」这个原版接口，不写死实体 id，别的模组坐骑零适配；她的近战 / 远程走位原样还原（走位意图不变，只是把「她走」换成「坐骑走」）；
- **一只坐骑同时只服务一位女仆**；一位主人可同时带多条链路。

### 卓越前线载具

- **女仆能开车、也能从车上打**：她坐**驾驶位（座位 0）**就能开（引擎认「第一乘客」，不要求是玩家）；把目标**同时写进炮塔与武器位的 AI 目标**，用载具**自己的炮弹**打；她背包里对得上的子弹会**自动搬进载具的弹药容器**，当前弹种没弹时会自动换弹种 / 换炮；
- **地面载具接敌会绕圈**（半径按车速与车体自适应，撞墙自动调头），不再「往敌人身上一撞就完事」；**真刹车**（进停车带就清输入 + 油门/转向/目标速度三件归零 + 打阻尼），不再一路漂移；**不撞主人**（停车距离按车体半宽自动放大，坦克约 3~4 格）；
- **四种飞行载具各接各的路**（面板「骑飞行载具·悬停与盘旋」对四类都生效）：**直升机**航向/俯仰走鼠标通道、高度走总距，跟随时比主人高三格悬停、接敌时升到敌人上方绕圈；**固定翼**没有竖直轴、不能悬停，改用引擎自带的盘旋（loiter），停在原地绕圈不再一路飞走；**飞艇**并入直升机的空战电路，接敌时自己升到敌人上方；**汤姆6**的油门与姿态原本只写给玩家、女仆一动不动，现在直接写推力 + 俯仰 + 机头，她会飞、会跟着你走。四类共用**急停**（到点抹平水平速度 + 每 0.5 秒收一次 + 水平速度钳进包络）；
- **投弹安全高度**（默认 20 格，可调 0~64）：她骑**飞行载具**且这一下要**往下投弹**时，机身会被抬到「**目标高度 + 这个格数**」，并且**没爬到位就按住这一发不投**——基洛夫那颗航空炸弹的爆炸半径是 42 格，贴地投弹等于把她自己也圈进爆心。**填 0 = 关掉**。

### 六台载具被开发者特意拉黑

骑乘指挥棒**选不中**、女仆也不去骑这六台卓越前线载具：

**Ju-87 斯图卡轰炸机 / A-10 雷电二攻击机 / AC-130H 空中炮艇 / KV-16 幽灵战斗机 / 汤姆 F6F / 迷你快艇**

拿指挥棒右击它们，她会回一句「这架 XXX 操作门槛太高（或只认玩家来开），我驾驭不了～」。**两类原因，都不在女仆这一侧**：① 前四台全是**固定翼**——没有竖直轴，高度只能由「速度 + 俯仰」积分出来，起飞要助跑、盘旋要维持速度，交给「去某个点」这一层意图必然是一头栽地或一路飞走（你自己飞都得练，女仆没有「练」这件事）；② 汤姆 F6F 与迷你快艇**在代码上直接认准玩家**——汤姆 F6F 的油门与姿态整段只写给「乘客是玩家」那一支，迷你快艇只有一个座位且走水面物理，**这两台的驾驶逻辑开发者做不出来**，与其继续打补丁，不如照实认人。**其余载具一律不受影响**；旧存档里已经坐上这六台的她会每拍自检并自动解绑。

## 空袭 —— 会飞的女仆

给女仆穿上**鞘翅**、带上**武器**和**可以飞行的道具**（**烟花火箭 / 孔雀羽扇 / 能上天的位移类法术**任一），她自己飞起来打怪——不再贴地追着砍。**装备不齐她不会飞**，切到任务当场就报缺哪一件。

| 模式 | 怎么打 | 武器位 |
|---|---|---|
| **近战空袭** | 爬到敌人上方 → 收翅俯冲 → 触底前一记近战 → 再起飞，循环 | 任意近战武器（剑/斧/三叉戟/重锤/模组近战） |
| **远程空袭** | 在天上盘旋并用手里的远程武器持续开火 | 任意远程武器（弓/弩/御币/三叉戟/模组弹射/枪械） |

- **三件套**：鞘翅（切任务后她自己穿到胸甲槽）+ 武器 + 可飞行道具（放背包就行）；远程空袭额外需要弹药，御币/三叉戟不消耗；**不响应自主切换**（不会被"主动参战"改任务、也不会自己换掉你给的武器）；
- **收翅俯冲那一击**：1.21.1 手持**重锤**时按玩家同款的**重锤下落加成**结算（含风爆的原地爆炸 + 自我顶起），落差按**本轮最高点**算——**飞得越高这一锤越狠，不设上限**；其它武器按原版**暴击 ×1.5** + 附魔。命中率三道保险（判定距离 4 格 / 收翅 2 tick 即可出手 / 对身边 2.5 格内其他合法敌对目标补一记），女仆一律跳过、**绝不误伤主人与宠物**，且要过视线；
- **索敌**：以她自己为圆心、**半径 50 格的球**，**锁定即持续瞄准**；视线只作为**新锁定**的门槛，"隔墙不出手"依然成立；
- **空袭牵引绳**：半径 **100 格**（可调，0 = 关闭）内找不到主人，就**立刻把她传送回你身边**——强制生效、无视地块、可以空中传送。防的是"她飞太高把目标打死后自己回不来"；
- **空袭期间**：自动传送一律让位（跟随拉回 / 跨维跟随 / 自保归位），但**持续滞空超过 15 秒会强制拉回**（落地即清零）；玩家手动「一键集合」与主人死亡传送照常生效；不触发自保，但**不免疫真实伤害**，照样会被打下来；滑翔/悬空/俯冲时不搭方块，落地自己放水/细雪接住；
- **默认开着「空袭免疫摔落伤害」**：整条链路是"高空盘旋 + 收翅俯冲"，落地缓冲万一没接住（背包没桶/落点被占/被打断）代价是十几点伤害甚至摔死——想按原版吃摔伤可在面板关掉；
- **空袭轰炸**：打完那一记、远程开火之后顺手放炸弹——**末地水晶**（黑曜石底座 + 水晶，底座起爆后还给她）、**重生锚**（要 1 颗萤石充能）、**床**（只在原版真会爆炸的维度放）、**投掷 TNT**（需要 TNT + 点火料；注册名带 tnt 的、方块继承原版 TntBlock 的模组 TNT 都认）。「轰炸破坏方块」与「轰炸伤到主人/友军」默认都**关**，爆炸火焰改成**粉色火焰**（不蔓延、自己灭、不点燃任何人）；
- **空袭 34 项数值全部可调**（起飞段时长与仰角、盘旋半径与期望高度、补推窗口、开火间隔与射程……），原本写死在代码里的数值全部搬进配置面板，**默认值与硬编码一字未改**。

## 扫帚模式 —— 骑着扫帚飞着打

给她一把**扫帚** + 任意**远程武器**，把任务切成**「扫帚模式」**，她自己骑上扫帚、用主手武器在空中打。**只有你手动指定才会进**——被怪袭击时她不会自己换扫帚。齐备三件：扫帚（背包里 / 世界里放着的都行）+ 远程武器 + 弹药（弓弩要箭；枪械要**对得上那把枪**的子弹，御币/三叉戟/能量枪不消耗）；缺件会报在气泡里并**原地待命**。

- **接敌**：先爬到敌人上方 **12 格**（可调 2~32）再**绕圈开火**，开火链路与远程空袭完全同款；
- **绕圈不是死圈**：半径随机缓动、旋向按 UUID 对半、转速缓慢游走，并保证**离敌最近距离**（默认 6 格）与接敌时同伴间距 4 格——几只女仆不会落在同一条射线上互相串击；
- **没敌人**：守家时沿工作范围巡逻（默认离地 8 格、不追圈外）；否则贴着你飞（起手/收手 6/3 格）；**没事干会落回地面待命**，不会一直挂在半空；
- **锁敌**：与空袭共用同一个索敌器（50 格发现、锁定后维持到 128 格、锁定期间**不要求视线**）；
- **牵引绳**：离参照点超 100 格连人带扫帚拉回（可调，0 = 关）；**守家时参照点是工作区圈心**，你走多远都不拽她；
- **空中避障**：卡墙脱困按她自己的身体判格（不钻一格死洞）、真被闷住立刻脱离、泡进岩浆或被点着立刻传送出去、多只女仆不叠罗汉不贴地；
- **限制**：她是骑乘状态，所以**只能用主手武器打**——不施法、不放 TNT / 末地水晶 / 重生锚 / 床。

## 三叉戟：近战 / 远程 / 激流旋转冲击

三叉戟在本模组里有三条明确分工，**近战与空袭两条线都能用**：

- **当近战武器**：攻击模式 / 近战空袭都认它（原版近战伤害与附魔照常结算）；
- **当远程武器**：远程空袭里能投掷，而且**不消耗弹药**。注意**附了激流就投不出去**——那是原版"水里突进"的设定；
- **激流旋转冲击**（默认开，可关）：主手拿着**带激流附魔的三叉戟**时，普通挥砍被**替换成旋转冲击**——近身 4 格内触发（地面要站在地上），空袭的**收翅俯冲那一记在空中也替换**（空中旋转期间不会自我摔伤）；旋转 16 tick（平躺 + 高速自转），撞到谁就结算一次伤害，**同一目标每次突进只打一下**。

## 其它玩法

- **指标石**（9 块平滑石 3×3）：手持它，视线指到的方块显示**绿框** → 右键锁定成**红框** → 再右击你的女仆绑定 → 从她脚下到锁定点之间所有空气方块变成**橙色幽灵方块**，她立刻一格一格填过去。材料先从她背包拿、不够从你的背包拉；创造模式视为无限；
- **压缩盒**（4 樱花木板放四角 + 4 钻石放四边中点 + 1 粉色染料放正中）：**只有 5 格，但每格能堆 114514 个**，放进女仆背包就等于是**她背包的延伸**——她真的会从盒子里拿材料、也会吃盒子里的食物。**v1.3.0 起禁入规则写死**：压缩盒本身与带附魔的物品一律不能放入（拒绝时给红字理由），原先那两个配置项已删除；
- **床铺互通**：女仆能睡原版 16 色床，**玩家也能睡女仆床并把它设为重生点**；
- **投喂认模组食物**：判定是「有食物属性 + 不在黑名单」，与 TLM 自己"女仆饿了吃"完全同口径；配置面板里是**勾选面板**（支持搜索翻页），默认不喂腐肉、生肉、金苹果那几类；
- **不得把方块搭在主人身上**：目标格被主人的碰撞箱**真正占着**时不搭（防把她挤住、卡住或盖住头），正常垫脚搭路不受影响。

## 核心系统（不需要 LLM）

- **排班表**（纸 + 墨囊）：手持右键打开全部女仆列表（跨维度也在列），点一只进去给她排一整天——早班 / 晚班 / 全天，工作时间平均分成 6 个任务时段、当前时段整行高亮、一键集合、自动在家模式、大范围活动与空闲散步；
- **建造**：按蓝图**一块一块真实搭出来**，材料真实消耗、缺料会暂停并告诉你补什么。四种蓝图来源——随包附赠 **81 套已授权蓝图**（首次运行自动解压）、LLM 对话现场生成、外部图纸文件（`.nbt/.snbt/.litematic/.schem/.json`）、AI 设计器。工地有金色框预览 + 青色幽灵投影（**Z 键旋转 90°**）、工头模式、进度持久化、缺料自动替代；
- **挖矿 / 伐木**：矿表白名单 + 价值评分选矿、连锁采集、透视感知（默认关）、搭方块防掉落 + 自动回收、**发呆看门狗**；伐木自动识别模组原木、随手补种、骨粉催熟；
- **烧制 / 酿造 / 农场 / 宰杀**：什么能烧就烧、多女仆各占一个炉子；酿造有批量与定向两种模式；农场连锁收获 / 批量种植 / 耕地标记制；宰杀按种类计数阈值自动宰杀，不误杀驯服宠物；
- **战斗与自保**：被动保命（低血回血 / 垫高 / 逃跑、环境险境自救）、回血阶梯、逃生手段、致死自动回魂符、**女仆自动复活**（重生点不可用就直接在主人所在位置复活，强制无视地块）、主动切换战斗并自动还原、**战斗模式分类表**（逐任务点名近战/远程/不参与）；
- **主人免伤三层防护**：伤害事件总闸 + 全部攻击注入点过滤 + 定期清仇恨——雪地打雪仗只会扔雪球，绝不挥刀；同主女仆之间也互不误伤；
- **单兵战术 / 贴身辅助 / 武器自动切换**：PVP 式走位、跳劈暴击、放风筝、举盾格挡；自动投喂与治疗；武器按 **DPS（最终伤害 × 攻速）+ 附魔 + 耐久**评分自动换——**判定全基于原版属性，没有武器黑名单**；
- **被动技能**：落地水 / 落地雪、岩浆逃生放水、主人死亡传送、搭路、飞行跟随（默认关）；
- **女仆安全与区块保载**：有主女仆所在区块持续保持加载；寻路主动绕开岩浆 / 火 / 仙人掌等危险方块；被困基岩顶层或掉出世界底部自动救援传回。

## AI 部分（需要自备 LLM 站点，全部可关）

- **AI 记忆**：重要事实、关系三元组、主人画像、工作笔记 + 日 / 3 日 / 周 / 月四级记忆日记，睡一觉自动整理并沉淀长期记忆，带人格种子与情绪快照；
- **主动对话 / 工作播报 / 自主决策**：她会自己开口（气泡 + 语音），关心你重伤、夜晚困倦、好感升级，也会在空闲时自己判断该去干什么；
- **17 个 AI 工具**：直接对她说「过来我身边 / 给我钻石 / 去打那只怪 / 记住我喜欢喝红茶 / 造一个 5×5 现代小屋」；
- **感知与情绪**：纯规则的感知系统（敌人出现 / 离开、主人受伤 / 低血、天气变化）+ PAD 三维情绪模型；
- **TTS 与语音**：内置**日语语音包（122 条，开箱即用、不联网）**，也可接自己的 TTS 或自建系统语音包。

> **需要联网的地方只有一处**：AI 对话 / 记忆 / 工具 / 蓝图生成需要你**自己填一个 OpenAI 兼容 API 站点**（模型、地址、密钥都在游戏内配置面板填写）。不填 = 这些功能自动不工作，模组其余全部功能照常，**不会偷偷发任何请求**。所有主动发言共用日配额（默认 40 次 / 天）控成本。

## 安装

1. 安装对应版本的 Minecraft / 加载器（1.20.1 + Forge 47.4.x，或 1.21.1 + NeoForge 21.1.250）；
2. 安装前置《车万女仆》TLM（1.20.1 用 Forge 版，1.21.1 用 NeoForge 版）；
3. 把 `promaid-*.jar` 放入 `mods` 文件夹（**必须在游戏完全退出后替换**——运行中换 jar 会让 ModLauncher 按旧偏移读到坏数据，表现为加载阶段莫名崩掉）；
4. 进游戏拿手册；想用 AI 功能（对话/记忆/工具/自主决策），先按手册第 3 章把 OpenAI 兼容 API 站点配好。

**升级注意**：装新 jar 前请**删掉 `mods` 里的旧版本 jar**（modId 相同，同时加载会启动失败）。旧存档兼容：物品 / 任务 / 蓝图 / 记忆等持久化数据沿用 `maid_smart` 命名空间。

## 专用服务器兼容

v1.1.0 起已修复两个服务端崩溃：

1. 主类内联配置界面 lambda 触发 `RuntimeDistCleaner` 拦截 → 客户端类型签名全部移入客户端专类；
2. 主动对话调用 TLM 客户端专用方法 `ChatClientInfo.fromMaid` → 改为服务端安全构造。

> 说明：开发者平时只玩单人模式，未对服务器做专门优化，若服务器上遇到其他问题，欢迎到 Issues 反馈，并请多加谅解。

## 与其他模组共存

- **「是，史蒂夫模型」(YSM)**：**不会崩**——v1.2.0（实测五百四十八）修掉了导致**黑屏进不去游戏**的 `ClassCastException`。两个图层在 YSM 下**现在都画**：**激流旋转特效从实测六百八十三 起绘制**（那一层不依赖任何骨骼）；**鞘翅从实测六百八十四 起也绘制**——非 Gecko 渲染器改走**固定身体偏移**（肩线 +1.86 格）。若在某个模型上位置明显不贴合（模型比例不同），说一声就调那一个数。1.20.1 与 1.21.1 同步修复；
- **其他模组武器**：武器判定基于原版攻击力属性，tacz / 卓越前线 / 拔刀剑 / 史诗战斗 / 万法皆通等模组武器天然可用，无需专门适配；
- **其他模组的鞘翅装备**（实测六百八十四）：**通用判据 = 这件装备对玩家能不能滑翔**（`ItemStack.canElytraFly`）。只要它能滑翔、**且它本身不是护甲**，女仆背上就会画那对翅膀——模组不需要为本模组做任何适配。**它本身是护甲的那一类**（鞘翅胸甲这种"护甲 + 滑翔钩子"）不叠翅膀，因为它自己就有护甲外观、再叠一层会穿模（原版 `ElytraLayer` 同样只服务 `Items.ELYTRA`）。放在 Curios 饰品栏的鞘翅仍照旧会被她取出来穿到胸甲槽（实测六百八十）。
